<objective>
Replace the "one `.typ` per docname whose shape depends on whether that docname is a master" rule
with two independently-resolved outputs per `typst_documents` entry: a docname-derived CONTENT file
carrying no template, and a target-derived WRAPPER file carrying the template application and an
`#include()` of its master's content.

Purpose: this is the phase's core structural change. It closes B-1 (COMP-03) and B-2 (COMP-04) by
construction — there is no longer a `.typ` that is "sometimes a master, sometimes a fragment" — and
it is where OUT-01's target-as-path reversal must land, because B-1's fix IS "compute include paths
from the wrapper's resolved location", the same computation OUT-01 changes.

Output: `typsphinx/writer.py` and `typsphinx/builder.py` rewritten around the split; the
`tests/test_two_layer_output_gate.py` strict-xfail markers removed so the module runs GREEN.

**Reversal notice.** OUT-01 deliberately REVERSES three locked decisions from v0.7.1 Phase 44 —
D-05 (a nested docname's output forced into that docname's own directory), D-06 and D-07 (a path in
a target rejected and truncated to its basename). The existing guard code implementing them is NOT
sacred. OUT-02 keeps the security half of the same guards.
</objective>
