## Unit test specification (append at the end of `tests/test_translator.py`; additions only)

Each test follows `test_literal_block_without_language`'s pattern at `tests/test_translator.py:1028`.
It builds a node, calls the visitor, `visit_Text` / `depart_Text` on a fresh `nodes.Text` of the same
text, then the departer, and asserts on `translator.astext()`. The module-level `simple_document`
fixture and the conftest `mock_builder` fixture are reused. The text is `">>> 1 + 1\n2"`.

| Test | Setup | Asserts |
|------|-------|---------|
| `test_doctest_block_defaults_to_python_fence` | `nodes.doctest_block(text=...)` with no language | the output contains `` "```python\n>>> 1 + 1\n2\n```" ``; after depart, `node.get("language") is None` (D-01, D-03: no doctree mutation) |
| `test_doctest_block_honours_existing_language` | the same node with its `language` attribute assigned `"pycon"` before visiting, simulating a third-party extension | the output contains `` "```pycon\n" `` and not `` "```python" `` (D-02) |
| `test_literal_block_without_language_keeps_bare_fence` | `nodes.literal_block(text="x = 1")` with no language | the output contains `` "```\nx = 1\n```" `` and not `` "```python" `` (D-03: the fallback is keyed on the node class) |
| `test_doctest_block_shares_list_item_wrapper` | `translator.in_list_item = True` and `translator.list_item_needs_separator = True` before visiting | the output contains `` "{\ncodly(number-format: none)\n```python\n>>> 1 + 1\n2\n```\n}" ``; after depart, `translator.list_item_needs_separator is True` (D-03: shared wrapper and separator re-arm) |
