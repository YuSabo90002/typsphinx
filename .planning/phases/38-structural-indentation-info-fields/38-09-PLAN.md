<objective>
Close the one verification gap Phase 38 left open: FLD-02's single-value label/value join is silently
bypassed whenever the enclosing `desc` is documented inside a bullet or enumerated list item. Sweep in
the two Warning-level findings the code review raised against this phase's own work.

Purpose: `visit_paragraph` and `depart_paragraph` test `self.in_list_item` before
`self._field_body_unwrapped_paragraph`, and nothing resets `in_list_item` for a
`field_list`/`field`/`field_body`/`paragraph` nested inside a list item. The pre-existing D-13 branch
therefore fires first and forces a `parbreak()` between a single-value field's label and its value —
reintroducing the exact pre-Phase-38 defect FLD-02/D-07 exists to remove. Neither
`38-CONTEXT.md`'s D-07/D-08 nor ROADMAP SC#5 scopes FLD-02 to exclude list items, so this is an unmet
requirement, not an accepted limitation.

Output: a reordered branch pair in `typsphinx/translator.py`, a new list-item fixture construct with
its own recorded RED, a positive table-cell regression construct for the `add_text` conversions this
phase shipped, the `SHARED_INDENT_STEP` import the sibling gate module already uses, and the
REQUIREMENTS.md/census bookkeeping gated behind all of it.
</objective>
