**Step 1 — sweep by property, not by line number.** Enumerate EVERY assertion in

classify it as either:

- **resolved-path** — the expected substring is part of a path the *builder
  resolved* (it will carry `os.sep` on Windows), or
- **config-echoed** — the expected substring is a `templates_path` /
  `typst_document_templates` value echoed verbatim from the fixture's `conf.py`

Record the full classification table in the evidence file. Do NOT start from
"line 255 is broken" — start from the property and let the sweep name the
offenders. If the sweep finds more than one resolved-path assertion, fix all of
them.

at the top of the module; build the expected substring with it so the separator
follows the platform:

```python
beta_bundle_tail = str(Path("_templates") / "nested")
```

assertion's failure message informative — it should still name what it expected
and print the message it searched.

particular `'_typst/inner'` must remain a literal forward slash: the fixture's
`conf.py` contains `templates_path = ["_templates", "_typst/inner"]`, and that
assertion's whole job is to prove the entry is reported as configured. Say so in
a short comment next to it so a future reader does not "fix" it too.
