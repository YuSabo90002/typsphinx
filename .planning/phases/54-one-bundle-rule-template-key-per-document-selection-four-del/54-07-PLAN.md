<objective>
Turn the exact-name claim on one reserved output file into a wholesale reservation of the reserved
output directory, and relocate the fixture whose docnames now live inside it — carrying all three of
its regression intents forward rather than losing two of them to the move.

Purpose: `_template/` stops being a filename and becomes an output namespace this phase writes every
key's bundle into. A source tree with a document under a directory of that name would write content
files straight into it, silently interleaving user documents with published template bundles — and
the current validator only claims one exact filename, which cannot see that. ROADMAP binding
constraint #1 records that the reservation costs an existing fixture and that Phase 54 must move it
and decide what replaces its regression intent; that fixture currently carries THREE intents at once
and none may be silently dropped.

Output: a prefix-reservation predicate in the pre-write validator, a negative fixture proving the
refusal names the offending docname, a relocated positive fixture carrying the multi-entry and
author-divergence intents, and both existing path references updated in the same commit.
</objective>
