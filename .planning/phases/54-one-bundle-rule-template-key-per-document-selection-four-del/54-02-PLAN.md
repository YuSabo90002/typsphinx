<objective>
Give the bundled `"typst"` template bundle a non-`.typ` file, widen the package-data glob so every
file kind in that directory reaches the wheel, and add a CI step that opens the built wheel and
proves it.

Purpose: ROADMAP binding constraint #8 — `pyproject.toml` declares a `.typ`-only glob, and the
editable install this project develops and CI-tests against masks the gap entirely. Once Phase 54
copies the whole bundle to `<outdir>/_template/typst/`, a non-`.typ` bundle file that never reached
the wheel is a silent runtime hole in every non-editable install. BLD-05 exists to close it, and
SC#4 says explicitly that inspecting the glob is not evidence: the check must build the actual wheel
and look inside.

Output: `typsphinx/templates/README.md`, a recursive package-data glob, and a `build`-job step that
fails if either regresses.
</objective>
