<objective>
Unregister `typst_template_assets` and, in the same commit, add this codebase's first
`config-inited` handler, so every removed configuration value announces itself by name instead of
going silently ignored.

Purpose: ROADMAP binding constraint #3 and `54-RESEARCH.md`'s Pitfall 2 are the same point from two
directions — Sphinx has no reverse "this name used to be registered" mechanism, so a `conf.py` still
setting a removed value builds successfully with zero diagnostic while doing something materially
different. There is no way to tell, after the fact, whether a historical build silently ignored the
setting, so the detection cannot be retrofitted: it ships now or never. Two of the three names
(`typst_authors`, removed at v0.7.1; `typst_toctree_defaults`, removed at v0.6.3) have already been
silent for two milestones; this closes all three through one mechanism.

Output: a small `removed_config` module, one `app.connect` line, one deleted `add_config_value`
line, and a gate that fails loudly if the mechanism the detection depends on ever disappears.
</objective>
