## Decisions Made

- **Did not copy `44.2-REVIEW.md` WR-01's literal suggested replacement text.** WR-01's wording ("whenever a *custom* `typst_template_mapping` is set and specifically omits `"author"` -- on any route") names only the explicit-mapping-omitting-author shape. Measured against `TemplateEngine.__init__`'s branch resolution: a `typst_package`-set engine with `typst_template_mapping` never passed at all resolves `self.parameter_mapping` to an empty dict with no "custom mapping" involved, and `typst_authors` still survives there. Copying WR-01 verbatim would have re-published a second narrower-than-code rule and re-failed this plan's own backstop truth. The published text instead names both surviving shapes explicitly, derived from `__init__`'s branch table (see `44.2-GATE-EVIDENCE-04.md` §5).
- **Also corrected `test_map_parameters_custom_mapping_omitting_author_keeps_typst_authors`'s pre-existing docstring**, which was not explicitly named by either task's action list but still used the narrowing "package-alone route" framing. The file-wide negative gate (`grep -c 'package-alone' tests/test_entry_metadata_precedence.py` == `0`) required it, and the plan's own `<measured_grounding>` §6 occurrence census had already identified this file's one pre-existing occurrence as an instance of the same defect this plan exists to close.
