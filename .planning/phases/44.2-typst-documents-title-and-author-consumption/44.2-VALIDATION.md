**Worktree-isolation preamble (CLAUDE.md, standing execution mode).** Every command above runs
inside the executor's own per-worktree venv. Provision first, then prefix everything with `uv run`:

```bash
env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev
```

**NixOS sandbox note.** `uv run <compiled-binary>` fails in this environment — invoke pytest as
`uv run python -m pytest`, never `uv run pytest`. A known set of integration tests fails
environmentally here; an executor must distinguish those from real RED before claiming a defect.

## Sampling Rate

- **After every task commit:** Run the Quick run command (isolates the three known-affected test
  modules plus the `test_package_only_config_gate.py` control group that must stay green)
- **After every plan wave:** Run the Full suite command
- **Before `/gsd-verify-work`:** Full suite green **plus** `uv run black --check .`,
  `uv run ruff check .`, `uv run mypy typsphinx/`, and `tests/test_corpus_gate.py`'s real-compile
  check (GATE-01 acceptance corpus, SC#6)
- **Max feedback latency:** 5 seconds (quick run); 80 seconds (full suite)

      build whose entry title **and** author both differ from `config.project` / `config.author`,
      asserted through `pypdf.PdfReader(...).metadata`. `pypdf` 6.14.2 is already a dev dependency;
      **no new runtime dependency is required or permitted here.**
- [ ] A parametrized precedence-matrix test — SC#2: present / absent / empty-string × `config`
      fallback × `typst_authors` × `typst_template_function["params"]`, driving
      `TemplateEngine.map_parameters()` directly (fast, no Sphinx build), plus one real-build case
      for the empty-string edge (research Pitfall 6 measured an asymmetry: an empty title yields an
      absent `/Title` key while an empty author yields an empty-string `/Author`).

      masters already differ on `entry[2]` but share `entry[3] == 'Test Author'`, so the author half
      is undetectable today. **Neither** half currently has an asserting test; planning must confirm
      whether the title-leak assertion is added in the same task.

      evidence, not prose (CONTEXT.md D-09). Its baseline is the **research-corrected** corpus
      numbers, not CONTEXT.md D-08's.
