## 5. Why `44.2-REVIEW.md` WR-01's literal suggested text was not used

WR-01's proposed rst:

> `typst_authors` survives as the sole source whenever a *custom*
> ``typst_template_mapping`` is set and specifically omits ``"author"`` --
> on any route, package-based or not.

This names only shape (b) — an explicitly-set mapping that omits `"author"`. It silently drops
shape (a): `typst_package` set with `typst_template_mapping` **never set at all**, where
`__init__` resolves `self.parameter_mapping` to an empty dict with no "custom mapping" involved.

§1's probe row falsifies WR-01 directly: shape 1 (`typst_package` set, `parameter_mapping` not
passed) produces `parameter_mapping={}` and `params['authors']` equal to the `typst_authors`
list — `typst_authors` survives — with **no custom `typst_template_mapping`** anywhere in the
construction. WR-01's wording, read literally, would classify this shape as one where the entry
author wins (no custom mapping was set to "specifically omit" anything), which is the opposite of
the measured behaviour.

The underlying finding (the "package-alone" framing is too narrow) was correct and is closed by
this plan. Only the specific replacement wording WR-01 suggested was itself incomplete; the text
actually published (§1 and §4 above) names both surviving shapes explicitly, derived from the
`__init__` branch table rather than transcribed from the review comment.
