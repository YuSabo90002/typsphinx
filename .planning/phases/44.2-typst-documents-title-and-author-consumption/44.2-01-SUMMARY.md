# Phase 44.2 Plan 01: `typst_documents` Title/Author Consumption Summary

**A `typst_documents` entry's own title and author now reach the compiled PDF's metadata (proven end-to-end via a real `-b typstpdf` compile read back through `pypdf`), and `typst_authors` no longer silently wins over the mapped author value on any route where `"author"` is an active mapping key.**

## Accomplishments

- `typsphinx/writer.py` gained `_resolve_entry_element()`, a module-level pure helper implementing D-01 (empty string is a value)/D-02 (absent/short/None -> silent fallback; non-`str` -> warn then fallback) fallback semantics, and `TypstWriter.translate()`'s `sphinx_metadata` construction now calls it twice instead of reading `config.project`/`config.author` directly (D-03) -- reaching all four template routes with no new template parameter.
- `typsphinx/template_engine.py`'s `map_parameters()` had its `typst_authors` block moved to seed `params["authors"]` FIRST, before the mapping loop, instead of overriding it LAST (D-05) -- unbreaking the `typst_authors` + bundled-template combination that previously crashed the build with `TypstError: expected string, found dictionary` (measured directly this session via a standalone probe).
- A permanent, `slow`-marked, `typst`+`pypdf`-guarded real-compile render gate (`tests/test_document_metadata_render_gate.py`) was recorded RED against the unfixed tree (a genuine metadata mismatch, not a build/compile failure) and is now GREEN, covering SC#1's happy path and D-01's asymmetric empty-string case.
- Three pre-existing test assertions were migrated to values measured from builds run in this session (D-07), and the package-alone control group (`tests/test_package_only_config_gate.py`, 12 tests, plus one named test in `test_template_engine.py`) was proven unaffected with **zero edits**.

## User-Visible Changes (source text for Phase 46 / REL-06)

1. **A `typst_documents` entry's own title/author now reach the rendered document, overriding `config.project`/`config.author`.** Measured with `tests/fixtures/entry_title_author_render_gate/` (`typst_documents = [("index", "index", "My Handbook", "Jane Doe")]`, `project = "Config Project Must Not Win"`, `author = "Config Author Must Not Win"`): **before** this phase, the compiled PDF's `/Title`/`/Author` were `'Config Project Must Not Win'` / `'Config Author Must Not Win'`; **after**, they are `'My Handbook'` / `'Jane Doe'`. Command: `uv run python -m pytest tests/test_document_metadata_render_gate.py::TestEntryTitleAuthorRenderGate::test_entry_title_and_author_reach_the_compiled_pdf -v`.

2. **An empty entry title/author is now a VALUE, not a fallback signal, with an asymmetric PDF-metadata consequence.** Measured with `tests/fixtures/entry_empty_metadata_render_gate/` (`typst_documents = [("index", "index", "", "")]`): an empty title produces a PDF with **no `/Title` key at all** (`reader.metadata.title is None`); an empty author produces a PDF with a **present, empty** `/Author` value (`reader.metadata.author == ""`). Command: `uv run python -m pytest tests/test_document_metadata_render_gate.py::TestEntryTitleAuthorRenderGate::test_empty_entry_elements_are_values_not_fallback_signals -v`.

3. **`typst_authors` is now overridden by the mapped author value on every route where `"author"` is an active `parameter_mapping` key, remaining authoritative only on the package-alone route whose custom mapping omits `"author"`.** `tests/test_config_template_mapping.py`'s `test_custom_mapping_applied_to_template` and `test_partial_custom_mapping` both confirm the entry's own title/author win on the default-template path. `tests/test_template_engine.py::TestTypstAuthorsConfig::test_typst_authors_through_pipeline_produces_native_array_of_dicts` confirms `typst_authors` reaches `render()` as a native `list[dict]` ONLY on the package-alone/`"author"`-omitting-mapping route; the full `tests/test_package_only_config_gate.py` suite (12 tests, control group) and `test_typst_authors_unset_or_empty_yields_no_authors_key_on_package_path` pass with **zero edits**, proving that route is unaffected.

4. **The `typst_authors` + bundled-template combination, which previously produced no PDF at all, now produces one when no `typst_documents` override supersedes it either.** MEASURED (not inferred) with a standalone probe fixture (`project = "Probe Project"`, `author = "Probe Author"`, `typst_authors = {"Jane Doe": {...}}`, no `typst_documents` set at all): `uv run python -m sphinx -b typstpdf <probe> <build>` now reports `build succeeded.` and generates a PDF (before this phase, the same shape produced a hard `TypstError: expected string, found dictionary` aggregate build failure). The emitted `.typ` shows `authors: ("Probe Author",)` — the plain `config.author` fallback wins over the `typst_authors` dict, matching finding #3 above.
