from that proven slice along three independent axes: the full element-semantics and precedence

`44.2-GATE-EVIDENCE-02.md` recording the matrix, the no-leak measurement and the four-route table.

    - `[("index", "out", "", "")]`, index 2 -> `""` (NOT `default`); index 3 -> `""`

    - `[("index", "out", "T", "A", "typst")]`, index 2 -> `"T"`, index 3 -> `"A"` (fifth element

    - `[("index", "a", "First", "A1"), ("index", "b", "Second", "A2")]`, index 2 -> `"First"`
      (first match wins, silently)

    - default mapping + `typst_authors` set + a metadata `author` value -> `params["authors"]` is

      `params["authors"]` IS the `typst_authors` `list[dict]`

    `TemplateEngine.render(...)`:
    - `typst_template_function = {"name": ..., "params": {"title": <explicit>}}` -> the rendered
