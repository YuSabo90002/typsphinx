<objective>
Cover the three relocation branches the end-to-end tracer does not reach, and audit the phase's own
evidence chain from a later wave than the one that produced it.

The D-10 render gate exercises exactly one branch end to end: the srcdir collision. The escape branch
and the cross-drive `ValueError` branch have no fixture — IMG-02 is not reachable through stock Sphinx
at all, which is why D-06 treats it as anomalous — so they are covered at the unit level, against
expected values this plan states literally rather than values read back out of the fixed code.

This plan is in wave 3 rather than wave 2 on purpose. Two hazards measured on this project govern it:
a plan that ASSERTS an emitted string must not sit in the same wave as the plan that CHANGES it
(their `files_modified` do not overlap, so nothing flags the conflict at plan time, yet both behave
correctly in isolation and the merge still fails), and a plan that AUDITS a measurement must not sit in
the same wave as the plan that TOOK it (the auditor then abstains on its own success criterion).

Purpose: close the branch coverage and produce the phase's close-out evidence.
Output: four additive unit tests and `50-BRANCH-EVIDENCE.md`.
</objective>
