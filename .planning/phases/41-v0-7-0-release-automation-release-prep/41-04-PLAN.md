<worktree_provisioning>
Worktree isolation is this project's STANDING execution mode (CLAUDE.md § "Worktree-isolated
execution"). Before ANY other command, run once from the worktree root:

1. `env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev`
2. `for t in uv ruff; do ln -sf "$(command -v $t)" ".venv/bin/$t"; done`

Then invoke EVERY command through `uv run`.

**The editable-install hazard is the whole design problem of this plan.** The main `.venv` holds a
PEP-660 editable finder that resolves `import typsphinx` to whichever checkout it was synced from. A
naive "before" build that imports the worktree's package would silently use HEAD's translator against
main's docs and produce a meaningless comparison. Task 1's procedure exists to make each build import
its OWN checkout's code, and each build must PROVE which code it imported before its PDF is trusted.
</worktree_provisioning>
