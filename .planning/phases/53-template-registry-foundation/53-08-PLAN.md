and one field DEEPER (a value inside a definition):

1. **WR-01** (`template_registry.py:261-262`): `declared = getattr(config, "typst_document_templates",
   None) or {}` is followed immediately by `declared.keys()`. Sphinx's `[dict]` config type only
   *warns*, so a truthy non-`dict` value -- a `list` is the plausible copy-paste-from-`typst_documents`
   typo -- reaches that line and crashes with a raw `AttributeError`, dumping an internal Sphinx
   traceback instead of this module's `ExtensionError` contract. An EMPTY list is falsy and correctly
   resolves to `{}`; only a truthy non-`dict` crashes.
2. **WR-02** (`template_registry.py:334-340`): `template = definition.get("template")` is gated on
   truthiness only, then handed straight to `os.path.join(srcdir, template)`. A truthy `template` that
   `os.path.join` cannot consume crashes with a raw `TypeError`.

Purpose: make the module's own error contract total over its input surface, so "every malformed
registry stops the build with a message naming the specific reason" is true of the whole config value
rather than of the shapes the resolver happened to anticipate.
Output: two guards in `typsphinx/template_registry.py`, a new end-to-end subprocess gate module with
its fixture, unit coverage in the existing registry test module, and a recorded pre-fix RED transcript.
