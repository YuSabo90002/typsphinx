<objective>
Expand the proven tracer slice with the validation pass: every malformed registry stops the build with
a message naming the specific reason, once per build and order-independently, following
`_validate_output_path_collisions()`'s accumulate-then-raise-once shape through an independent
`ExtensionError` (D-03).

Key-shape validation is denylist enumeration only, each of ROADMAP SC#4's seven cases judged
individually with its own case-specific message (D-01) — no allowlist regex, not even as a trailing
catch-all, because SC#3 requires a message naming the specific reason. The denylist is exactly those
seven cases and nothing more (D-02).

Purpose: close the door on unsafe registry keys and template paths at validation time, in this phase,
before Phase 54 creates the `mkdir()`/`copytree()` write sites that would be their exploit surface.
Output: the validation half of `typsphinx/template_registry.py` plus its parametrized test coverage.
</objective>

   they are today. `resolve_registry_key()` reads `entry[4]` when `len(entry) > 4` and ignores the
   rest. No requirement covers longer tuples and D-02's "do not exceed the roadmap text" stance
   applies.

   `TemplateRegistryEntry` object, not per-entry copies. The dataclass is frozen, so sharing is safe,
   and 53-02's TPL-05 test asserts identity with `is` rather than equality.
3. **CONF-15 — a definition carrying NEITHER `template` nor `package`.** Assumption: accepted. The
   requirement text forbids carrying *both*; it says nothing about neither, and a definition with
   neither resolves exactly like TPL-03's "nothing set" shape (bundled `base.typ`). Rejecting it would
   exceed the roadmap text, which D-02 forbids.
4. **CONF-16 — case sensitivity of the reserved key.** Assumption, and it is answered directly by
   D-04: only the literal string `typst` is reserved. `Typst` and `TYPST` pass as ordinary
   user-defined keys. The bundle-directory collision this admits on case-insensitive filesystems is
   explicitly Phase 54's problem (CONTEXT § Deferred Ideas).

One further shape no probe row named, decided and flagged for the same reason: an **unknown sub-key
inside a definition dict** (for example a typo alongside `template`). Assumption: accepted and
ignored, per D-02's do-not-exceed-the-roadmap-text stance. Note that `typst_elements` takes the
opposite approach (a fail-loud allowlist), so this is a deliberate divergence, not an oversight.
