**Module `tests/test_registry_documentation_gate.py`.** Header docstring cites Phase 56 and D-06,
and states in its own words the design constraint copied from `tests/test_docs_contract_claims_gate.py`:
it imports no `typst`, spawns no `sphinx-build`, reads only `.py` and `.rst` text, and therefore
never skips. Import only `ast`, `re`, `pathlib` and `pytest`.

Discovery is run-time, never a hardcoded file list. `_iter_source_modules()` returns
`sorted(TYPSPHINX_PKG_DIR.glob("*.py"))` where `TYPSPHINX_PKG_DIR` is derived from
`Path(__file__).resolve().parent.parent / "typsphinx"` — a repository-relative derivation only, no
absolute path literal anywhere in the module.

`_discover_error_shapes()` parses each module with `ast.parse(text)` and walks for every `ast.Call`
whose `func` is an `ast.Name` with `id == "ExtensionError"`, taking argument 0. Reduce that argument
to a list of **literal chunks** in source order:
  - `ast.Constant` with a `str` value contributes one chunk.
  - `ast.JoinedStr` contributes one chunk per `ast.Constant` value in `.values`; each
    `ast.FormattedValue` contributes no chunk and acts as a chunk boundary. (CPython already merges
    Python's implicit adjacent string-literal concatenation at parse time, which is what reaches
    `template_registry.py:422`'s two-token message without any special handling; the scanner must not
    re-implement concatenation.)
  - `ast.Call` whose `func` is an `ast.Name` naming a function defined at module scope in the SAME
    module: resolve one level of indirection by locating that `ast.FunctionDef` and decomposing its
    single `ast.Return` value the same way. This is the only indirection level supported, and it is
    what reaches `builder.py:2151`, whose argument is a call to `_conf17_violation_message` rather
    than an inline f-string. If a call cannot be resolved this way, the scanner must raise a test
    failure naming the file and line — never silently drop it.
Each discovered shape is a record carrying the module name, the line number, the ordered chunk list,
and a normalized joined form built by joining the chunks with a single placeholder token between
adjacent chunks.

written reason, in the exact shape `EXCLUDED_CLAIM_PAGES` uses. Exactly three entries, each with the

`docs/source/user_guide/configuration.rst`, locates the `When the Build Stops` heading line by its
