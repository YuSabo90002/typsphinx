**Why it is RED on this tree:** today `TypstBuilder.write()` calls
`_validate_output_path_collisions()` and `_validate_registry_key_references()` at its pre-write
slot, but neither reads `self.config.templates_path` at all — this is the FIRST read of that config
value anywhere in `typsphinx/`. The build proceeds to `finish()`, where
`_copy_used_template_bundles()` copies the `"paper"` key's resolved bundle directory
(`_templates/`) wholesale to `<outdir>/_template/paper/`, republishing the project's own Sphinx
Jinja override directory into public build output — exactly the WR-01 defect this phase closes.
`typsphinx/` is untouched by this task (`git status --porcelain typsphinx/` produces no output).
