## Collision severity (refusal vs warning)

| Option | Description | Selected |
|--------|-------------|----------|
| `ExtensionError` refusal | Stop the build, naming the key and the colliding `templates_path` entry. Matches CONF-17 / OUT-07 / CONF-14, all of which raise. Cost: a v0.8.x project with `typst_template = "_templates/…"` plus a matching `templates_path` cannot build v0.9.0 until it moves the template | ✓ |
| `logger.warning` + skip the copy | Warn and skip that key's bundle copy, following D-07/CONF-19's precedent. Measured cost: the wrapper's `#import "/_template/<key>/….typ"` then points at a file that was never written — `-b typstpdf` fails inside `typst.compile()`, `-b typst` reports success over an uncompilable `.typ` tree | |

**User's choice:** `ExtensionError` refusal
**Notes:** No option that copies less than the whole bundle was offered — "one bundle rule, no
exceptions" (PROJECT.md / Phase 54 OUT-04) is locked and was not re-opened.

| Option | Description | Selected |
|--------|-------------|----------|
| Accumulate every offender, raise once | The `_validate_output_path_collisions()` / bundle-destination-collision idiom (`builder.py:625`, `:1658`); `sorted()` iteration keeps the message byte-identical | ✓ |
| Raise on the first offender | `_validate_registry_key_references()`'s shape (`builder.py:780`) — chosen there only because `resolve_registry_key()` already owned CONF-14's message text | |

**User's choice:** Accumulate and raise once
**Notes:** Area closed after two questions; detection was fixed as a path-relationship test against
the live `templates_path` values (is / contains / is contained by), never a name match on the
literal string `_templates`.

## `templates_path` check placement

| Option | Description | Selected |
|--------|-------------|----------|
| Pre-write pass at the top of `write()` | Co-located with CR-01's hoisted check, after `resolve_template_registry()` / `_validate_registry_key_references()` and before `prepare_writing()`. Consequence: the checked key set is what `typst_documents` references (incl. `_default_typst_documents()` defaults), not the write-time accumulator — the same declaration-wide scope Phase 53's D-05 chose | ✓ |
| Immediately before the copy in `finish()` | Co-located with today's A-01 guard (`builder.py:1632`); sees only genuinely-used keys, but refuses after the whole `.typ` tree is already on disk — the same residue CR-01 objects to | |

**User's choice:** Pre-write pass at the top of `write()`

| Option | Description | Selected |
|--------|-------------|----------|
| Keep the `finish()`-side A-01 guard | Accept the duplication: many existing tests drive `write_doc()` / `_write_typst_files()` and `finish()` without ever calling `write()` (the reason the lazy registry fallback at `builder.py:1322-1331` exists), and the pre-write pass never runs on that path | ✓ |
| Remove it, rely on the pre-write pass | One check, one message shape. Cost: A-01 violations go undetected for every caller that bypasses `write()` | |

**User's choice:** Keep it
**Notes:** Whether the pre-write pass is one method or two was left to Claude.
