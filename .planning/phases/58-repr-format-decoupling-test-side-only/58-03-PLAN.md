  `test_out02_escape_target_gate.py` and `test_builder.py`, used by the zero-path-valued assertion.
- `MINIMUM_FILES_SWEPT` — an integer floor for the non-vacuity assertion. Set it to `100`. Measured

**The sweep helper** `_collect_pass_criterion_repr_sites()`, returning a
`tuple[frozenset[tuple[str, int]], int]` of the hit set and the number of files parsed:

- Iterate `TESTS_ROOT.rglob("*.py")`.
- Skip any path with `__pycache__` in its parts.
- Skip the guard's own file by resolved-path identity — compare `candidate.resolve()` against
  `pathlib.Path(__file__).resolve()`, NOT against a hardcoded filename string. D-09 requires the
  self-exclusion because the guard's own recorded allowlist and docstring carry the very tokens the
  sweep looks for in source form; deriving the exclusion from `__file__` means renaming the module
  cannot silently break it.
- Read each file with `read_text(encoding="utf-8")`. The explicit encoding is not optional: without
  it Python uses the platform's locale encoding, and the `windows-latest` lane would fail on any
  non-ASCII byte in any test file. This project has already paid for that class of defect once.
- Parse with `ast.parse(source, filename=str(candidate))`. Wrap the parse in a `try`/`except
  SyntaxError` that calls `pytest.fail` naming the offending path — an unparseable file under
  `tests/` is itself a finding and must never be silently skipped, because a silent skip is a hole in
  exactly the enumeration this guard exists to keep honest.
- For every `ast.Assert` node reachable from the module, walk ONLY `node.test` — never `node.msg`.
  This is the whole reason the several-hundred diagnostic-only occurrences in failure-message
  f-strings do not pollute the result, and it is the single most important line in the module: say so
  in a comment.
- Record a hit for a `ast.Call` whose `func` is an `ast.Name` with `id == "repr"`, and for an
  `ast.FormattedValue` whose `conversion` is `114` — the integer encoding of the `!r` conversion
  (`115` is `!s`, `-1` is none). Cite that encoding in a comment.
- Key each hit as `candidate.relative_to(TESTS_ROOT).as_posix()` plus the node's `lineno`. The
  `as_posix()` call is mandatory: on Windows a raw relative path renders with backslashes and would
  never compare equal to the allowlist's forward-slash form.
