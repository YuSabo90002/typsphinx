## Task 2 — SC#2: emission-site enumeration and two-way agreement

**Method:** every place a named-argument key can enter the dict that eventually reaches
`TemplateEngine.render()`'s `#show: <func>.with(...)` call, enumerated from the code (not from
`templates.rst`'s prose), each named by file and line, with the key names it can contribute and the
condition under which it does. Read from `typsphinx/writer.py` (current HEAD, post-45.1-05) and
`typsphinx/template_engine.py` (same).

### The eight emission sites

1. **`template_engine.py:251-256`** (`TemplateEngine.__init__`'s `typst_template_function`
   parsing). Contributes: the D-D predicate `self.typst_template_params_specified` (`True` iff the
   dict form carries a `"params"` key, even an empty one) and `self.typst_template_params` (that
   dict's own, arbitrary key names — NOT part of the nine-name default contract; this is the
   "Custom Parameters" route `templates.rst` documents separately). Condition: `typst_template_function`
   is a `dict` containing `"params"`.

2. **`template_engine.py:471-479`** (`map_parameters()`'s mapping loop). Contributes: `title`,
   `authors`, `date` (the `DEFAULT_PARAMETER_MAPPING` targets — `project`→`title`, `author`→
   `authors`, `release`→`date`) into `params`. Condition: the mapping's `sphinx_key` is present in
   the `sphinx_metadata` dict `writer.py` passes in (always true for `project`/`author`/`release`,
   since `writer.py:271-279` always supplies all three).

3. **`template_engine.py:485-492`** (the `if not self.typst_package:` back-fill gate, D-05).
   Contributes: default values for `title` (`""`), `authors` (`()`), `date` (`None`) — the SAME
   three names as site 2, filling any of them site 2 left absent. Condition: `self.typst_package`
   is falsy (every non-package route) AND the key is not already in `params` (site 2 already wrote
   it in the ordinary case, so this site is the guard against an absent mapping entry, not a second
   source of new names).

4. **`template_engine.py:502-512`** (the `ELEMENTS_ALLOWLIST` merge). Contributes: `papersize`,
   `fontsize`, `lang` (the allowlist's three keys) into `params`. Condition: the caller-supplied
   `typst_elements` argument (`writer.py`'s `effective_elements`, sites 5-6 below) contains that
   key; an unrecognized key raises `ExtensionError` rather than silently entering `params` (D-06/
   D-07) — this is a closed enumeration, not an open one.

5. **`writer.py:301-304`** (the `auto_lang` derivation). Contributes: the auto-derived value of
   `lang` (feeds site 4/6, not itself a direct `params` write). Condition: gated by
   `template_engine.uses_bundled_default_template()` — `True` for every non-package route
   (CONF-12/D-I) — AND `derive_typst_lang(config.language)` returns non-`None` (a well-formed
   2-3-letter ASCII head).

6. **`writer.py:321-323`** (the `effective_elements` pre-merge). Contributes: decides whether
   site 5's `auto_lang` reaches site 4's input at all, and at what precedence. A plain dict union
   `{"lang": auto_lang} | (typst_elements or {})` whose RIGHT operand (the user's own
   `typst_elements`) wins on collision — an explicit `typst_elements["lang"]` always overrides the
   auto-derived value, structurally, with no precedence logic inside `map_parameters()` itself.

7. **`writer.py:331-332`** (`extract_toctree_options()` + `params.update()`). Contributes:
   `toctree_maxdepth`, `toctree_numbered`, `toctree_caption` into `params`, unconditionally
   overwriting (there is no collision in practice — these three names appear nowhere else in the
   default mapping or the elements allowlist). Condition: the master document's own doctree
   contains at least one `addnodes.toctree` node (the FIRST one found, per CONTEXT.md item 10);
   an empty dict (no contribution) when none is present — this is the DOC-13 empty edge
   `TestDocumentedParamsContractGateNoToctree` locks.

8. **`template_engine.py:693-696`** (`render()`'s exclusive branch, D-B/D-D). This is the FINAL
   gate, not a name source: when site 1's `typst_template_params_specified` is `True`, sites 2-7's
   entire contribution to `params` is discarded wholesale and ONLY site 1's own declared `params`
   dict is emitted. Otherwise, whatever sites 2-7 wrote into `params` is emitted unchanged. SC#2's
   comparison below concerns the **default (site 1 absent) route only** — the case `templates.rst`
   "Standard Parameters" documents; the exclusive route is documented separately under "Custom
   Parameters" and is, by CONF-11's own design, an open-ended, user-declared set with no fixed
   contract to check agreement against.

### The two-way agreement statement

**Union of contributable names on the default (no declared `params`) route** — sites 2, 3, 4, 7
(site 1 is inactive when `params` is absent; site 5-6 feed site 4's `lang` input; site 8 passes
sites 2-7 through unchanged):

```
{title, authors, date, papersize, fontsize, lang, toctree_maxdepth, toctree_numbered, toctree_caption}
```

Nine names.

**Names `docs/source/user_guide/templates.rst` "Standard Parameters" publishes** (as rewritten by
plan 45.1-05):

```
{title, authors, date, papersize, fontsize, lang, toctree_maxdepth, toctree_numbered, toctree_caption}
```

Nine names.

**Direction 1 — nothing emitted is unpublished.** Every name the code can contribute on the default
route (the nine-name union above) appears in `templates.rst`'s published list. No emission site
above contributes a name absent from that list.

**Direction 2 — nothing published is unemitted.** Every name `templates.rst` publishes (the same
nine-name list) is backed by a real, enumerated emission site above (`title`/`authors`/`date` by
sites 2-3; `papersize`/`fontsize` by site 4; `lang` by sites 4-6; `toctree_maxdepth`/
`toctree_numbered`/`toctree_caption` by site 7). No published name is aspirational or dead prose.

**Verdict: the two sets are equal.** This is proved by set equality, not containment in either
direction alone — `tests/test_documented_params_contract_gate.py::TestDocumentedParamsContractGate::
test_emitted_key_set_equals_published_key_set_exactly` checks this exact equality with a real
build's emitted output, and the emission-site walk above independently confirms it from the code.
