## 1. `partial_params_template` — `typst_template` route, partial `params`

**Command:**
```
uv run python -m sphinx -b typstpdf tests/fixtures/params_exclusivity_gate/partial_params_template <build-dir>
```

**Exit code:** `2` (non-zero — a real compile fatal)

**Verbatim Typst error:**
```
Typst compilation failed at <build-dir>/index.typ: TypstError: unexpected argument: title
ERROR: Failed to compile <build-dir>/index.typ: Typst compilation failed: TypstError: unexpected argument: title
```

**Verbatim emitted `#show:` region** (`index.typ`, pre-fix):
```typst
#show: project.with(
  title: "Partial Params Template Gate",
  authors: ("Gate Fixture Author",),
  date: "1.0",
  papersize: "a4",
  toctree_maxdepth: 2,
  toctree_numbered: false,
  toctree_caption: "Partial Contents",
  subtitle: "A Gate Subtitle",
)
```

The pre-fix additive union carries all seven auto-derived/element/toctree keys PLUS the one declared
`subtitle` key — eight named arguments against a template (`_templates/partial.typ`) that declares
only `subtitle` and the trailing positional `body`. Typst rejects the first undeclared argument it
encounters (`title`) and aborts the compile. Post-fix (plan 02, real build verified separately)
this fixture emits exactly one named argument, `subtitle`, and compiles to a valid PDF.

## 2. `zero_params_default` — bundled-default route, `params: {}`

**Command:**
```
uv run python -m sphinx -b typstpdf tests/fixtures/params_exclusivity_gate/zero_params_default <build-dir>
```

**Exit code:** `0` — this route's RED is **structural, not a compile fatal**: `templates/base.typ`'s
inlined `project()` function declares defaults for all nine documented parameters, so a full
auto-derived argument list compiles cleanly both pre- and post-fix. The amended definition of RED
this project adopted in v0.7.0 applies here (see STATE.md's "Standing GATE-01 bar" paragraph): RED is
the structural difference in the emitted argument list, not the exit code.

**Verbatim emitted `#show:` region** (`index.typ`, pre-fix):
```typst
#show: project.with(
  title: "Zero Params Default Gate",
  authors: ("Gate Fixture Author",),
  date: "1.0",
  lang: "en",
  papersize: "a4",
  fontsize: 11pt,
  toctree_maxdepth: none,
  toctree_numbered: true,
  toctree_caption: none,
)
```

Nine named arguments are emitted despite `typst_template_function["params"]` being explicitly `{}`.
Post-fix (plan 02, real build verified separately) this fixture emits zero named arguments — the
`#show: project.with(` line is immediately followed by the closing `)` line — and still compiles to a
valid PDF, because `templates/base.typ`'s own defaults absorb the omission.

## 3. `package_params` — `typst_package` route, mapping-supplied key absent from `params`

**Command:**
```
uv run python -m sphinx -b typstpdf tests/fixtures/params_exclusivity_gate/package_params <build-dir>
```

**Exit code:** `0` — this route also compiles cleanly pre-fix (no toctree, and the D-05
`if not self.typst_package:` back-fill gate already withholds `authors`/`date` on the package route),
so its RED is likewise the structural presence of the mapped `title` key, matching CONTEXT.md
`<specifics>` item 4's measurement.

**Verbatim emitted `#show:` region** (`index.typ`, pre-fix):
```typst
#show: ieee.with(
  title: "Package Params Gate",
  abstract: "A fixture abstract proving the package-route path compiles for real, end to end, through a genuine typst.compile() call.",
  paper-size: "a4",
)
```

`title` — produced by `typst_template_mapping = {"project": "title"}`, an auto-derived value
completely independent of `typst_template_function["params"]` — leaks into the call even though
`params` does not name `title`. This is the exact case D-C's documentation-only stance depends on:
the package route needs no special-cased code once `params` is authoritative, because the mapping
output feeds the same auto-derived `params` dict the exclusive branch discards wholesale. Post-fix
(plan 02, real build verified separately) this fixture emits exactly the two declared keys
(`abstract`, `paper-size`) and no `title`, and still compiles to a valid PDF (the
`@preview/charged-ieee:0.1.4` package fetch succeeds).
