<objective>
Migrate the seven assertion and docstring sites in `tests/test_topics.py` that encode the pre-TOC-01
heading contract, and prove each one still detects something.

This file is D-04's highest-risk category. Four of its seven sites are *negative* assertions —
"no heading was emitted here". After plan 01 landed, the literal those four search for can no longer
be produced by any code path in `typsphinx/`, so all four now pass while detecting nothing. They did
not go red; they went silent. A mechanical find-and-replace over positive assertions would have missed
every one of them.

Purpose: SC#6 asks for deliberate, traceable, re-proved test updates rather than a keyword sweep. The
proof obligation differs by assertion shape, and this plan makes that difference explicit instead of
manufacturing a uniform RED that some of these sites cannot honestly produce.

Output: seven rewritten sites, a per-guard non-vacuity proof, the SC#4 test-side rationale rewrite,
and `44.1-GATE-EVIDENCE-02.md`.

Scope fence (from plan 01's prohibitions, restated because it binds here too): this plan edits test
text only. It does not touch `typsphinx/` except transiently, under `git checkout`, for the pre-fix
measurement in task 3 — and it restores it in the same task.
</objective>

| `git checkout <sha> -- typsphinx/translator.py` -> the working tree | A transient revert of production source inside a worktree that other tasks and the merge step will read |
| test process -> `import typsphinx` | An editable-install finder can resolve the import outside this worktree, silently detaching the measurement from the revert |
