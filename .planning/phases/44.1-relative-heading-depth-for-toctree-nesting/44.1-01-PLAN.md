**typst.query call shape, measured:** `typst.query(input, 'heading', field='level', root=...)`
returns a **JSON string**, not a Python list — it must be `json.loads`-ed. Querying without `field`
returns the full heading dicts, where a single-`Text` heading's `body` is
`{'func': 'text', 'text': '<the title>'}`, which is how a heading is located by title rather than by
index. `root=` must be the build directory because the emitted `include()` paths are relative.
