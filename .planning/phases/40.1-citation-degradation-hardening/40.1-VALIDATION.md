## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest 8.4+ (project pin, `pyproject.toml` `[tool.pytest.ini_options]`) |
| **Config file** | `pyproject.toml` — `testpaths = ["tests"]`, markers `slow`/`integration`, `filterwarnings = ["error::DeprecationWarning", "error::PendingDeprecationWarning"]` |
| **Quick run command** | `uv run pytest tests/test_citation_degradation_gate.py -x` (new module, D-02) |
| **Full suite command** | `uv run pytest -m "not slow"` (fast tier) |
| **Slow / corpus gate** | `uv run pytest tests/test_corpus_gate.py -m slow` — D-06's non-regression evidence; must be **observed green at least once**, a skip does not satisfy it |
| **Estimated runtime** | fast tier ~60–120s; corpus gate is the long pole |

**Worktree note (CLAUDE.md § Worktree-isolated execution):** every command above runs through `uv run`,
after `env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev` in the worktree. This is
mandatory, not conditional — without it pytest imports the unchanged main-tree package and gates stay
RED after a correct fix.

## Sampling Rate

- **After every task commit:** `uv run pytest tests/test_citation_degradation_gate.py -x` **plus**
  `uv run pytest tests/test_citation_render_gate.py -x` (the frozen SC#5 control — cheap enough to run
  every commit, and it is the thing SC#5 measures)
- **After every plan wave:** `uv run pytest -m "not slow"`, plus `black --check .`, `ruff check .`,
  `mypy typsphinx/`
- **Before `/gsd-verify-work`:** full suite green (`uv run pytest`); corpus gate
  (`tests/test_corpus_gate.py -m slow`) observed green at least once; Phase 40's citation fixture
  `.typ` confirmed byte-identical to its pre-phase output (SC#5)
- **Max feedback latency:** ~30s for the per-commit pair
