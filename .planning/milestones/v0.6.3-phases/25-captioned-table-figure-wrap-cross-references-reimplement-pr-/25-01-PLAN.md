<objective>
Reimplement PR#98's captioned-table figure wrap against current `translator.py`: a
`.. table:: Caption` (and `csv-table`/`list-table` with a caption) renders as
`figure(table(...), caption: {...}, kind: table)` with native "Table N" numbering,
composes with the existing `:width:` block wrap, keeps its caption on the 2nd-and-later
table (stale-buffer root-cause fix), and carries a single Typst `<label>` derived from
its docutils id without colliding with the table's `_emit_id_anchors` anchors.

Purpose: Delivers TBL-01 (figure wrap, no stray heading, caption-less stays plain, inline
markup, caption+width, 2nd-table stale-buffer) and TBL-02 (`<label>` derivation + no
double-anchor collision) at the translator layer, verified by fast unit tests. The
real-compile GATE-01 fixture that proves the whole pipeline is Plan 25-02 (Wave 2).

Output: `typsphinx/translator.py` (caption buffering + figure-wrap emission + deferred
id-anchoring) and adapted PR#98 unit tests in `tests/test_translator.py`.
</objective>

## Trust Boundaries

| rST/docutils caption text -> Typst source | Build-time, single-process. Input is the doc author's OWN reStructuredText (trusted author building their own docs). No network, no auth, no secrets, no filesystem writes beyond Sphinx's normal build output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-25-01 | Tampering | caption text -> `caption: {...}` code block in depart_table | low | mitigate | Route ALL caption text through the EXISTING inline-visitor chain (visit_Text -> `escape_typst_string()`), never node.astext(); introduce no new raw-string interpolation path. |
| T-25-02 | Denial of Service (build-time) | duplicate/dangling Typst `<label>` aborting the whole-document compile | medium | mitigate | Critical Pitfall 3 fix: skip visit_table's unconditional `_emit_id_anchors` for captioned tables and defer to `_emit_id_anchors(node, skip_ids={ids[0]})` in depart_table; the real-compile GATE-01 fixture (Plan 25-02) is the catch-all. |
| T-25-SC | Tampering | npm/pip/cargo installs | low | accept | No package installs: this phase adds zero runtime dependencies (RESEARCH Package Legitimacy Audit: not applicable). typst-py/pypdf are already pinned. |

**Why no high-severity threats (block_on=high, ASVS L1):** the change is a pure
build-time docutils->Typst string transformation with no new untrusted-input surface,
no network/auth/secrets, and reuses the single existing escaping primitive
(`escape_typst_string`). The dominant risk (T-25-02) is a build-availability DoS, capped
at medium and directly mitigated by the phase's primary implementation task.
