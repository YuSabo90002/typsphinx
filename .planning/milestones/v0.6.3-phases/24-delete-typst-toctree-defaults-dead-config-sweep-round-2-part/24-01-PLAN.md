<objective>
Remove the registered-but-inert `typst_toctree_defaults` config value from every user-facing
and code surface so it is no longer presented as a supported option. This is CONF-05: a **pure
deletion** of a grep-proven-inert value with **zero consumers** — `TypstWriter.translate` →
`template_engine.extract_toctree_options` reads toctree options off the docutils node
(`toctree.get("maxdepth", …)`), never off `app.config.typst_toctree_defaults`. There is therefore
**no config→output change**, GATE-01 does not apply, and no `typst.compile()` regression fixture is
required (ROADMAP Phase 24 Note; CONTEXT D-04).

The exact analog is the v0.6.2 CONF-01 removal (`typst_output_dir` / `typst_author_params`):
registration line + docs/examples/README/test surfaces removed, historical CHANGELOG lines left
intact. Mirror that treatment exactly.

Purpose: Stop advertising an option that does nothing, closing round 2 (part B) of the dead-config
sweep. Documented toctree control stays the per-directive path (`:maxdepth:`, `:numbered:`,
`:caption:`).

Output: No new symbols, files, or config. Seven surfaces edited/deleted (see files_modified);
CHANGELOG.md deliberately untouched (D-02); docs/configuration.rst surgically edited but KEPT (D-03).
</objective>
