### `typsphinx/template_engine.py` — `_derive_typst_lang()` helper (utility, transform)

**Analog:** `_convert_to_authors_tuple()`, `:542-561` — the existing precedent for a small, pure, no-I/O Sphinx-metadata→Typst-value conversion helper living in this exact module.

```python
# Existing sibling pattern to mirror (shape/placement), :542-561
def _convert_to_authors_tuple(self, author_value: Any) -> tuple:
    if isinstance(author_value, (list, tuple)):
        return tuple(author_value)
    elif isinstance(author_value, str):
        authors = [a.strip() for a in author_value.split(",")]
        return tuple(authors)
    else:
        return (str(author_value),)
```

**New helper to add** (module-level function per RESEARCH.md's recommendation, placed near this method):
```python
def _derive_typst_lang(sphinx_language: str) -> str | None:
    """D-02: split at first `_`/`-`/`@`, lowercase. D-03: warn+omit (return
    None) if the result isn't 2-3 alphabetic chars."""
    import re
    head = re.split(r"[_\-@]", sphinx_language, maxsplit=1)[0].lower()
    if len(head) in (2, 3) and head.isalpha():
        return head
    logger.warning(
        f"typsphinx: could not derive a Typst 'lang' from Sphinx "
        f"'language' = {sphinx_language!r} -- omitting 'lang' (falling "
        f"back to the template's own default)."
    )
    return None
```

**Warning-message shape to match (D-03's `logger.warning` idiom)** — two existing calls in this exact file/sibling file set the house style (module-level `logger = logging.getLogger(__name__)`, f-string, no exception):
```python
# template_engine.py:203-206
logger.warning(
    f"Custom template not found: {self.template_path}. "
    f"Falling back to default template."
)
# builder.py:554-558
logger.warning(
    "Both 'typst_package' and 'typst_template' are configured; "
    "this combination is unsupported. 'typst_template' will be "
    "honoured and 'typst_package' will be ignored."
)
```
Use `{sphinx_language!r}` (repr, not raw `str()`), matching the ASVS-aligned convention RESEARCH.md's Security Domain section calls out.

### `typsphinx/template_engine.py` — load-result provenance (service, transform)

**Analog:** itself — `load_template()`, `:182-229` (the priority walk being refactored into a provenance-recording resolver).

**Current state (full method, priority order 1→2→3):**
```python
def load_template(self) -> str:
    template_content = None
    if self.template_path:
        template_content = self._try_load_file(self.template_path)
        if template_content is None:
            logger.warning(
                f"Custom template not found: {self.template_path}. "
                f"Falling back to default template."
            )
    if template_content is None and self.search_paths:
        for search_dir in self.search_paths:
            candidate_path = Path(search_dir) / self.template_name
            template_content = self._try_load_file(str(candidate_path))
            if template_content is not None:
                logger.debug(f"Loaded template from: {candidate_path}")
                break
    if template_content is None:
        default_path = self.get_default_template_path()
        template_content = self._try_load_file(default_path)
        if template_content is None:
            raise FileNotFoundError(
                f"Default template not found at: {default_path}. "
                f"Package installation may be corrupted."
            )
    return template_content
```

**Required shape (RESEARCH.md Pattern 1 — zero blast radius on the ~5 existing call sites + `builder.py:585`):**
```python
@dataclass(frozen=True)
class TemplateResolution:
    content: str
    source: str  # "explicit" | "search" | "default"

class TemplateEngine:
    def resolve_template(self) -> TemplateResolution:
        # same three-branch walk as today's load_template(), but returns
        # TemplateResolution(content, source) instead of a bare str
        ...

    def load_template(self) -> str:
        """UNCHANGED public contract."""
        return self.resolve_template().content
```
D-06 predicate: `template_engine.resolve_template().source == "default"` is `True` only for Priority 3 (bundled `base.typ`), `False` for BOTH Priority 1 (explicit `typst_template`) AND Priority 2 (search-path hit — the `<srcdir>/base.typ` shadow case lives here). Do not add a second, independent existence check for `<srcdir>/base.typ` (Pitfall 1/Anti-Pattern in RESEARCH.md).

**Existing test this refactor must not break** — mirror its shape for the new provenance test:
```python
# tests/test_template_engine.py:59-79
def test_template_search_priority(self, tmp_path):
    """Test that user template directory has priority over default"""
    user_dir = tmp_path / "user_templates"
    user_dir.mkdir()
    (user_dir / "base.typ").write_text("#let project() = { /* user template */ }")
    default_dir = tmp_path / "default_templates"
    default_dir.mkdir()
    (default_dir / "base.typ").write_text("#let project() = { /* default template */ }")

    engine = TemplateEngine(
        template_name="base.typ", search_paths=[str(user_dir), str(default_dir)]
    )
    template = engine.load_template()
    assert "user template" in template
    assert "default template" not in template
```
New provenance tests should add a parallel `engine.resolve_template().source == "search"` assertion alongside this exact fixture shape, plus new cases for `"explicit"` and `"default"` and a `<srcdir>/base.typ`-shadow-specific case.

### `typsphinx/writer.py` — auto-`lang` derivation + pre-merge (controller, request-response)

**Analog:** itself, `:199-220` — the existing `sphinx_metadata`/`typst_elements` construction immediately preceding the existing `map_parameters()` call. This is the exact insertion point.

**Current state:**
```python
sphinx_metadata = {
    "project": config.project,
    "author": config.author,
    "release": config.release,
}

# CONF-04: typst_elements is passed to map_parameters() as its OWN
# keyword argument -- never merged into sphinx_metadata (D-05). ...
typst_elements = getattr(config, "typst_elements", {})

# Map parameters
params = template_engine.map_parameters(
    sphinx_metadata, typst_elements=typst_elements

```

**Required insertion (after the existing `TemplateEngine(...)` construction at `:189-197`, before the `map_parameters()` call):**
```python
resolution = template_engine.resolve_template()
is_default_template = resolution.source == "default"

sphinx_language = getattr(config, "language", "en")  # Sphinx guarantees non-None str
auto_lang = _derive_typst_lang(sphinx_language) if is_default_template else None

typst_elements = getattr(config, "typst_elements", {})
effective_elements = (
    {"lang": auto_lang} if auto_lang else {}
) | typst_elements  # explicit always wins (D-05) -- plain dict union

params = template_engine.map_parameters(
    sphinx_metadata, typst_elements=effective_elements
)
```

**Critical naming pitfall (Pitfall 5, RESEARCH.md):** do NOT reuse the bare `typst_elements` variable name for both the raw config value and the merged result — name the merged dict `effective_elements` and pass that into `map_parameters(typst_elements=effective_elements)`. A copy-paste reuse of `typst_elements` silently drops auto-derivation while every negative-path test still passes.

**Must NOT be added to `builder.py::_write_template_file()`** (`:521-592`) — that method only writes the shared `_template.typ` once per build and never builds a `params` dict; it must gain zero `lang`/`language` awareness (WR-04, Pattern 5 in RESEARCH.md).

### `tests/test_typst_lang_gate.py` (new, GATE-01 real-compile)

**Analog:** `tests/test_typst_elements_pass_through_gate.py` (full file, 423 lines) — mirror verbatim.

**Reusable helpers to copy near-verbatim** (lines 77-119 of the analog):
```python
def _run_sphinx_build(source_dir, build_dir, builder):
    return subprocess.run(
        [sys.executable, "-m", "sphinx", "-b", builder, str(source_dir), str(build_dir)],
        capture_output=True, text=True,
    )

def _show_rule_call_region(text: str) -> str:
    """Slices the emitted master text down to just the
    #show: <func>.with(...) call, so per-case assertions search this
    region in isolation."""
    start_match = re.search(r"^#show: \w+\.with\($", text, re.MULTILINE)
    start = start_match.start()
    end_match = re.search(r"^\)$", text[start:], re.MULTILINE)
    end = start + end_match.end()
    return text[start:end]
```
**Never** invoke via `["uv", "run", "sphinx-build", ...]` — always `sys.executable -m sphinx` (NixOS sandbox hazard, Pitfall 6).

**pypdf extraction pattern to reuse verbatim** (from `tests/test_pdf_render_gate.py`, repeated ~10×, e.g. lines 384-385/465-466/549-550):
```python
reader = pypdf.PdfReader(str(pdf_output))
full_text = "\n".join(page.extract_text() for page in reader.pages)
```

**New, genuinely-novel-to-this-codebase helper (Pitfall 3 — NBSP-aware regex, no existing helper to copy):**
```python
import re
assert re.search(r"Abbildung\s+1", full_text)
assert re.search(r"Tabelle\s+1", full_text)
```
Do NOT use a literal ASCII-space substring check (`"Abbildung 1" in full_text`) — Typst emits the supplement/number separator as NBSP (`\xa0`), which silently fails an ASCII-space literal match while passing `\s+`.

**GATE-01 skip convention** (`TYPST_AVAILABLE`/`PYPDF_AVAILABLE`) — grep `tests/test_pdf_render_gate.py` head for the exact `@pytest.mark.skipif` pattern and reuse identically.

**D-07 split-proof cases to implement:**
- `ja`: real `-b typstpdf` compile succeeds AND `.typ`-source (via `_show_rule_call_region`) contains `lang: "ja"` — font-independent, source-only assertion.
- `de`: real compile succeeds AND pypdf-extracted text matches `Abbildung\s+1` / `Tabelle\s+1` — the actual supplement-language-linkage proof.
- Precedence (SC#2): `language = "de"` + explicit `typst_elements = {"lang": "ja"}` → emitted `.typ` shows `lang: "ja"`, not `"de"`.
- D-08 case ①: custom `typst_template` (no `lang` declared) + `language = "ja"` → build succeeds, no `lang` injected.
- D-08 case ②: `<srcdir>/base.typ` shadow (no `typst_template`/`typst_package`, shadow declares no `lang`) + `language = "ja"` → build succeeds, no `lang` injected. This is the direct proof of the D-06 judgment boundary.
- SC#4 malformed: e.g. `language = "日本語"` or `""` → build does not abort.

## Shared Patterns

### The allowlist/`base.typ` same-commit contract (CONF-04 precedent, restated for `lang`)
**Source:** `typsphinx/template_engine.py:44-53` (comment) + `typsphinx/templates/base.typ:39-48`
**Apply to:** `typsphinx/template_engine.py` (`ELEMENTS_ALLOWLIST`) and `typsphinx/templates/base.typ` (`project()` signature) — must land in the SAME commit/task. See Pitfall 2 above.

### `logger.warning` fail-soft idiom (D-03)
**Source:** `typsphinx/template_engine.py:203-206`, `typsphinx/builder.py:554-558`
**Apply to:** `_derive_typst_lang()`'s warn-and-omit path. Module-level `logger = logging.getLogger(__name__)` (already present at `template_engine.py:15`), f-string, `{value!r}` interpolation, no exception raised. Never use `ExtensionError`/fail-loud for a malformed `language` value (D-03, explicit rejection — contrast with Phase 26's fail-loud for unknown `typst_elements` *keys*, a different class of validation).

### `map_parameters()`'s merge order — DO NOT MODIFY beyond the allowlist line
**Source:** `typsphinx/template_engine.py:263-327`
**Apply to:** any file touching precedence. Order is: `parameter_mapping` → package-path back-fill guard (`if not self.typst_package`) → `typst_authors` override → elements merge (LAST). The elements-merge-last property is what makes D-05's precedence work with zero new branching — pre-merge `auto_lang` into the `typst_elements` dict in `writer.py` BEFORE it reaches `map_parameters()`; never add a new parameter or new branch inside `map_parameters()` itself.

### GATE-01 real-compile fixture skeleton
**Source:** `tests/test_typst_elements_pass_through_gate.py` (full file)
**Apply to:** `tests/test_typst_lang_gate.py`. Class-scoped `@staticmethod pytest.fixture` builds ONCE via `-b typstpdf`, shared read-only across independent assertion tests; `_run_sphinx_build()`/`_show_rule_call_region()` helpers reused verbatim; a `TestPreFixBasisFailureProof`-style class records the fail-pre-fix basis (GATE-01 convention).

### pypdf PDF-text-extraction pattern
