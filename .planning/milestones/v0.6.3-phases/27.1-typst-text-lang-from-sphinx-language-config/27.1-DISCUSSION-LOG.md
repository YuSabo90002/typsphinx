## 言語コードの変換規則

### Q1: region をサポートするか

| Option | Description | Selected |
|--------|-------------|----------|
| lang のみ | `zh_TW` でも `lang: "zh"` だけ渡す。supplement は簡体字「图 1」。base.typ 変更は `lang` 1パラメータで SC#5 の文面をそのまま守る。zh_TW の限界は docs 明記 + region は deferred | ✓ |
| lang + region 両方 | `zh_TW` → `lang:"zh", region:"TW"` で繁体字「圖 1」。base.typ に `region` も追加するため ROADMAP SC#5 と PROJECT.md の不変量記述を再改訂する必要あり | |

## GATE-01 の証明方法

### Q1: SC#1（ja で「図 N」「表 N」）をどう証明するか

| Option | Description | Selected |
|--------|-------------|----------|
| ja は .typ + de で PDF 抽出 | `ja` は実コンパイル成功 + `.typ` に `lang: "ja"`（フォント非依存）、supplement 連動は `de` の PDF 抽出で "Abbildung 1"/"Tabelle 1"（ラテン文字で全 OS 安定）。SC#1 の文面解釈を変えるため CONTEXT に明記 | ✓ |
| ja で PDF 抽出アサート | SC#1 の文面どおり。ローカル/macOS/Windows は通る見込みだが ubuntu ランナーに CJK フォントが無ければ CI 限定 flaky | |
| ja 抽出 + フォント同梱 | CJK フォントをフィクスチャに同梱し `font_paths` で渡して決定的にする。ランタイム依存は増えないが数 MB のバイナリ + ライセンス表記が増える | |

**User's choice:** ja は .typ + de で PDF 抽出
**Notes:** 決定の根拠は実測 — `ignore_system_fonts=True` で `lang: "ja"` はコンパイル成功するが抽出は `'\x00\xa01: cap'`（豆腐）。CI は 3-OS マトリクス。区切りが NBSP (`\xa0`) である点も計測で判明。→ CONTEXT D-07（+ SC#1 解釈変更の警告）。

## 「既定テンプレート」判定の境界

### Q1: 自動導出を「既定テンプレート経路のみ」に限る判定の定め方

| Option | Description | Selected |
|--------|-------------|----------|
| ロード結果で判定 | 「実際に使うテンプレートが同梱 base.typ か」で決める（`load_template` の解決結果を利用）。srcdir-local `base.typ` の穴も `search_paths` が将来増えた場合も構造的に塞がる。`load_template` に小さな手入れが必要 | ✓ |
| REQUIREMENTS の文面どおり | `typst_template is None and typst_package is None` だけで判定。最小実装だが srcdir-local `base.typ` ユーザーは `language` 設定だけでビルドが落ちる（既知の限界として明記 + deferred） | |
| srcdir の存在チェックを追加 | `<srcdir>/base.typ` の有無を判定に足す簡易対応。一行で済むが `load_template` の優先順位が2箇所に重複し規則変更でズレる | |

**User's choice:** ロード結果で判定
**Notes:** 提示前に実測で穴を確認 — `TemplateEngine(template_path=None, search_paths=[tmpdir])` に `<tmpdir>/base.typ` を置くと `get_template_content()` がユーザーのファイルを返す（同梱 base.typ を黙って上書き）。`writer.py:191` と `builder.py:576` の両方が `search_paths=[srcdir]` を渡す。docs 未記載、`tests/test_template_engine.py` にテストあり。→ CONTEXT D-06（+ D-08 で回帰2ケース）。
