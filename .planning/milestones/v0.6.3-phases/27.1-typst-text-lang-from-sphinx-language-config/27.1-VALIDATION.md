## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest (project-pinned via `pyproject.toml`) |
| **Config file** | `pyproject.toml` (`[tool.pytest.ini_options]`) |
| **Quick run command** | `uv run pytest tests/test_template_engine.py tests/test_config.py -q` (unit-level: conversion helper, load-result provenance, allowlist merge — no compile) |
| **Full suite command** | `uv run pytest -q -m "not slow"` |
| **Estimated runtime** | ~60–150 seconds (the new GATE-01 fixtures invoke real `sphinx-build` + `typst.compile()` subprocesses) |

**Environment caveats (CLAUDE.md + project memory):**

- **Worktree-isolated execution is the standing mode.** Provision first with
  `env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev`, then run **everything** via `uv run`.
  Without this the executor edits the worktree but pytest imports the unchanged main-tree package.
- **Executors inside a worktree see ~45–48 pre-existing environmental failures** across
  `tests/test_integration_{advanced,basic,multi_doc,nested_toctree}.py` and `tests/test_examples_basic.py`
  (they shell out to `uv run sphinx-build`, hitting the NixOS `stub-ld` linker error). These are **not**
  regressions. Clean-signal invocation inside a worktree:
  `uv run python -m pytest -q --ignore=tests/test_integration_advanced.py --ignore=tests/test_integration_basic.py --ignore=tests/test_integration_multi_doc.py --ignore=tests/test_integration_nested_toctree.py --ignore=tests/test_examples_basic.py`
- **Never trust an executor's worktree pass/fail counts as the project baseline** — re-run the suite on the
  main tree in the orchestrator's post-merge gate.
- **New fixtures must invoke Sphinx as `sys.executable -m sphinx`**, never `["uv", "run", "sphinx-build", ...]`
  (the `tests/test_pdf_render_gate.py::_run_sphinx_build_typst` pattern).
- Verified available this session: typst-py 0.15.0, pypdf 6.14.2, sphinx 9.1.0. CJK system fonts on the
  ubuntu CI runner remain **unconfirmed** — which is exactly why D-07 splits the SC#1 proof (`ja` via
  `.typ` source, supplement linkage via `de` + pypdf) instead of asserting on extracted CJK glyphs.

## Wave 0 Requirements

- [ ] `tests/test_typst_lang_gate.py` — new GATE-01 real-compile module, mirroring
      `tests/test_typst_elements_pass_through_gate.py`'s `_run_sphinx_build()` / `_show_rule_call_region()`
      helpers, plus a **new NBSP-aware assertion helper** for the `de` pypdf extraction
      (`re.search(r"Abbildung\s+1", text)` — Python's `\s` matches U+00A0; an ASCII-space literal does not).

      CONTEXT.md's measured table + malformed inputs, and load-result-provenance behavior across all three
