## Gate module specification (`tests/test_doctest_block_render_gate.py`)

Module docstring: name TRN-01, TRN-02 and GATE-01, and D-06's two contexts and three shapes. Name
the single module-scoped build, the text-mode UTF-8 reads (a Windows CR-newline translation cannot
spuriously fail the gate), and `74-RED-EVIDENCE.md` as the RED record.

Imports: `re`, `subprocess`, `sys`, `textwrap`, `pathlib.Path`, `pytest`, and the
`import typst  # noqa: F401` availability guard setting `TYPST_AVAILABLE`, as in the analog.

Constants:
- `FIXTURE_DIR = Path(__file__).parent / "fixtures" / "doctest_block_render_gate"`
- `MASTER_DOCNAMES = ["index", "context_a_paragraph", "context_b_nonfirst_positions"]`
- `SHAPE_SENTINELS = ["ctx_a_paragraph", "ctx_b1_definition", "ctx_b2_bullet"]`
- `UNKNOWN_DOCTEST_BLOCK = "unknown node type: <doctest_block"`
- `FENCE_OPEN = "codly(number-format: none)\n```python\n"`

Helpers:
- `_run_sphinx_build_typstpdf(source_dir, build_dir)`: `subprocess.run([sys.executable, "-m", "sphinx", "-b", "typstpdf", str(source_dir), str(build_dir)], capture_output=True, text=True, encoding="utf-8", errors="replace")`. The explicit decode keeps a non-ASCII warning text from raising on a Windows runner.
- `_wrapper_pdf_path(build_dir, docname)` returns `build_dir / f"{docname}-out.pdf"`.
- `_assert_pdf_magic(path, docname)`: exists, non-empty, first four bytes `b"%PDF"`, with the docname in every message.
- `_read_typ(build_dir, docname)` returns `(build_dir / f"{docname}.typ").read_text(encoding="utf-8")`.
- `_source_doctest_block(rst_name, sentinel)` reads `FIXTURE_DIR / rst_name` as UTF-8. It finds the first line whose `lstrip()` starts with `">>> " + sentinel`, collects lines until the first whitespace-only line, and returns `textwrap.dedent("\n".join(lines))`. It fails with a clear message when the sentinel is absent.
- `_unknown_doctest_chunks(output)` returns `re.findall(r"unknown node type: <doctest_block.*?</doctest_block>", output, flags=re.DOTALL)`. A warning spans several lines, because the node's text follows the tag.

Module fixture `doctest_block_build(tmp_path_factory)`, `scope="module"`: build `FIXTURE_DIR` into
`tmp_path_factory.mktemp("doctest_block_render_gate") / "_build"` and return `(result, build_dir)`.

Class `TestDoctestBlockRenderGate`, under `@pytest.mark.skipif(not TYPST_AVAILABLE, ...)`. The
eleven test ids are fixed; 74-03, 74-06 and the evidence refer to them by name.

| Test | Asserts |
|------|---------|
| `test_build_exits_zero_without_compile_failure` | `returncode == 0`; `"master document(s) failed"` absent from stderr; `"expected semicolon or line break"` absent from stdout + stderr |
| `test_build_reports_no_doctest_block_unknown_node` | `UNKNOWN_DOCTEST_BLOCK` absent from stdout + stderr |
| `test_no_unknown_node_warning_for_shape[sentinel]`, parametrized over `SHAPE_SENTINELS` | no `_unknown_doctest_chunks(stdout + stderr)` chunk contains the sentinel |
| `test_master_writes_pdf[docname]`, parametrized over `MASTER_DOCNAMES` | `_assert_pdf_magic(_wrapper_pdf_path(build_dir, docname), docname)` |
| `test_context_a_paragraph_line_structure` | on `context_a_paragraph.typ`: `FENCE_OPEN + block + "\n```\n"` is present, where `block` is the `ctx_a_paragraph` source block; `'text(">>> '` is absent; the index of `Trailing paragraph after the doctest block.` is greater than the fence's index |
| `test_context_b1_definition_list_line_structure` | on `context_b_nonfirst_positions.typ`: `'terms.item(text("Examples:")'` is present; `FENCE_OPEN + block_b1 + "\n```"` is present; `'text(">>> '` is absent; `Leading paragraph of the definition.` precedes the fence |
| `test_context_b2_bullet_list_item_line_structure` | on `context_b_nonfirst_positions.typ`: `"{\n" + FENCE_OPEN + block_b2 + "\n```\n}"` is present. That is the list-item `{ }` wrapper `visit_literal_block` opens only when `in_list_item` is true. `'text(">>> '` is absent, and `Leading paragraph in the list item.` precedes the fence, which precedes `Trailing paragraph in the same list item.` |

Every membership assertion comes before any `str.index` call, so a RED failure message shows the
missing fence rather than a `ValueError`.
