leaf-module discipline, mirroring MSG-02's on the product side.

1. Normalize with `os.fspath(value)` into a local name.
2. If the normalized value is not a `str`, raise `TypeError` naming the received type — a `bytes`

3. If the normalized value is the empty string, raise `ValueError` with a message stating that an
   empty value would match every text vacuously. This is the edge-probe `empty` resolution: the
   predicate must never return a vacuous `True`, because a vacuous `True` is exactly the tautology
   SC#2 forbids.
4. Return the two-disjunct rule from D-01: the normalized value appears in `text`, OR the builtin
   representation of the normalized value appears in `text`. Two disjuncts, not four.

across (`!r` today, 57-11's hardcoded `'{value}'`, and MSG-02's delimiter-aware helper after Phase
