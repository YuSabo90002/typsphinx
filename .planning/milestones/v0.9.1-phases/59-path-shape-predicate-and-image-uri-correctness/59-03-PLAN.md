`escape_typst_string()` before interpolating it into the `image("...")` literal, so what reaches
Typst is a string its parser accepts.

own wave, after the builder plans, because plan 04's gates assert on the emitted literal that this
plan and plan 02 both change — a plan that changes an emitted string and a plan that asserts on it
must not share a wave (ROADMAP constraint 4), and every plan in this phase appends to the single
`59-WINDOWS-URI-EVIDENCE.md`, so two plans in one wave would collide there too.

Output: the one-line routing change in `typsphinx/translator.py` plus
`tests/test_image_literal_escaping_gate.py`, whose gate is deliberately built from a RELATIVE image
URI so it never touches the escape branch plan 02 rewrote and can be recorded RED and turned GREEN by
this plan alone.
