<worktree_provisioning>
Provision with `env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev --extra docs --python 3.13.13`
and run every tool through `uv run` (`CLAUDE.md` § "Worktree-isolated execution"). The `docs` extra
is what lets the CHANGELOG page gate run instead of skipping (constraint 12).

**Locale inside tox.** tox 4 forwards `LANG` and `LANGUAGE` into the environment but drops
`LC_ALL`. `LC_ALL=C` alone therefore leaves Sphinx on the host's `ja_JP.UTF-8` inside tox, and a
grep of that log for English text returns a false zero. Run tox's docs builds as
`LANG=C LANGUAGE=C LC_ALL=C uv run tox -e docs-html`. Require the English `build succeeded` line
in the log.

**Evidence key lines.** Every `KEY = value` line carries the bare value only; put any explanation on
the next line. The verify fails on any key line containing an opening parenthesis.

**pytest counts.** The summary line is wrapped in `=` characters. Extract counts with an unanchored
`grep -oE '[0-9]+ (passed|skipped|failed|errors?)'`, never a line-start anchor.

**Scratch.** Use your own `mktemp -d` directory, recorded as `SCRATCH_72_05`, and prefix helpers
`p7205_`.

**Commits.** Plain `git commit`. Never a GSD commit helper. Never write `72-VERIFICATION.md`.
</worktree_provisioning>
