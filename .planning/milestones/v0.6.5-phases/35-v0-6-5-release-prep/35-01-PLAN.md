## Environment prerequisite (read before Task 1)

Worktree-isolated execution is this repository's standing mode. If `.git` is a FILE (a `gitdir:`
pointer) you are in an isolated worktree and the worktree owns no virtualenv yet. Provision it before
running anything, then run every command through `uv run`:

1. `env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev`
2. `for t in uv ruff; do [ -x "$(command -v $t)" ] && ln -sf "$(command -v $t)" ".venv/bin/$t"; done`

Step 2 is the NixOS stub-ld shim: `uv sync` installs generic-linux ELF copies of `uv` and `ruff` into
`.venv/bin`, which NixOS cannot exec, producing ~45 spurious integration-test failures that are a
provisioning miss, not a regression. With the shim applied, a worktree full suite is identical to the
main tree's. Without the provisioning step entirely, pytest imports the UNCHANGED main-tree package
and this plan's gates stay red after a correct fix.
