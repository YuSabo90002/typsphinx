## Environment prerequisite (read before Task 1 — this plan needs the docs extra)

If `.git` is a FILE you are in an isolated worktree. Provision it before running anything, then run
every command through `uv run`:

1. `env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev --extra docs`
2. `for t in uv ruff; do [ -x "$(command -v $t)" ] && ln -sf "$(command -v $t)" ".venv/bin/$t"; done`

Two deviations from the other plans in this phase, both load-bearing:

- The `--extra docs` group is required because Task 1 runs `tox -e docs-html` and `tox -e docs-pdf`.
  That group is already pinned in `pyproject.toml`; adding it introduces no new dependency and must
  not change `uv.lock`.
- The shim in step 2 is not optional here. Without it, `uv run ruff` fails with a dynamic-linker error
  and roughly 45 integration tests fail on the same cause. Those failures are a provisioning miss, not
  a regression — but the correct response is to apply the shim and re-run, never to record the failed
  numbers as evidence or to exclude the affected files.
