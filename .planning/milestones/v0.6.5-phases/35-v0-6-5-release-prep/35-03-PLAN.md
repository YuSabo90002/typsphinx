## Environment prerequisite (read before Task 1)

If `.git` is a FILE you are in an isolated worktree. Provision it before running anything, then run
every command through `uv run`:

1. `env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev`
2. `for t in uv ruff; do [ -x "$(command -v $t)" ] && ln -sf "$(command -v $t)" ".venv/bin/$t"; done`

Step 2 is the NixOS stub-ld shim. Without step 1, `import typsphinx` resolves to the unchanged
main-tree package and `typsphinx.__version__` will report the old release no matter what you edit
here — the exact failure this plan's SC#1 probe is designed to catch.
