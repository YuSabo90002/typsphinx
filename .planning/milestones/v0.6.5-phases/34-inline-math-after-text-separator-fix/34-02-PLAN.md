<objective>
Land the MATH-01 fix: make `visit_math` and `visit_math_block` participate in the separator
protocols every other inline/block visitor already implements, turning Plan 01's RED gate GREEN on
both emission paths.

Purpose: RESEARCH.md measured the root cause as a scope gap, not a visit-ordering bug —
`visit_math` calls only `_add_paragraph_separator()`, which is deliberately a no-op inside a list
item (`visit_paragraph` never sets `in_paragraph` there) and inside the five code-mode concat
contexts. So math emitted after a sibling in those contexts juxtaposes with zero separator
characters and `typst.compile()` rejects the document. The fix is not new design: it applies the
existing, tested `visit_literal` pattern to the one visitor pair that was never retrofitted.

Output: a minimal, precedent-matching diff in `typsphinx/translator.py` plus the GREEN half of the
phase's RED→GREEN evidence record.
</objective>
