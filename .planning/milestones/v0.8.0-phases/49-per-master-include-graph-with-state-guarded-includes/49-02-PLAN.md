## Flagged planner assumptions

- **The two masters must be in ONE Sphinx project, not two.** Sphinx's `env` is per-project, so a
  two-project fixture would exercise nothing about per-master divergence. The second master is
  therefore an `:orphan:`-fielded document that appears in no toctree — which is exactly the shape
  `tests/fixtures/template_named_dir_master/conf.py` already uses for two genuinely distinct masters.
- **`root_doc` must be set explicitly wherever the first master is not named `index`.** The mirror-pair
  fixture has no `index` document, so its `conf.py` sets `root_doc`; forgetting it makes Sphinx fail on
  a missing root rather than exercising the fixture.
