**Step 1 — add the page-level helper.** Add one method to the `_Build` dataclass, named
`pdf_page_texts`, taking the same `target: str` argument the existing `pdf_text` takes and returning a
list with one extracted-text string per PDF page. Build it from the SAME idiom `pdf_text` already uses —
resolve `self.pdf_dir / target.replace(".typ", ".pdf")`, open it with `pypdf.PdfReader(str(path))`, and
read `page.extract_text()` for each page — differing only in that it returns the per-page list instead
of joining. Do not invent a variant idiom and do not change `pdf_text`.

**Step 2 — measure before asserting.** Add the new test method to `TestThreeMasterGate`, named
`test_three_masters_each_carry_their_full_include_set_in_pdf`, taking the existing module-scoped
`all_builds` fixture. Before writing a single assertion, run the module once with a temporary print of
each master's extracted text and page count, and READ what `pypdf` actually returns for this fixture.
Then write the assertions against that measured reality. This ordering is not optional: `pypdf`
extraction is known on this project to introduce artifacts (a spurious zero-width space at an unrelated
glyph boundary was measured during v0.7.0), and an assertion written from expectation rather than from
measurement is how a gate ends up either red for a non-defect or silently vacuous.

**Step 3 — write the assertions, per the `<behavior>` block.** Three warnings about what makes an
assertion here real rather than trivial:

- The fixture's `typst_documents` titles each embed that master's own token, so an assertion that a
  master's own token is present in its own PDF is satisfied by the TITLE PAGE alone and proves nothing
  about the body. Do not write that assertion. Write the cross-master ABSENCE form instead — the other
  two masters' tokens must not appear in this master's PDF — which the title page cannot satisfy
  accidentally.
- The `mid` document carries a heading and no marker, which is exactly why it is the right probe for
  "non-shared, non-marker-bearing content is not silently dropped". Use its heading text for both the
  m1/m3 presence assertions and the m2 absence assertion.
- Use `_marker_count` for the marker counts (it is a plain substring count) and the new
  `pdf_page_texts` helper for the page-level assertions. Keep the existing method's assertion style.

Give the new method a docstring that states, in two or three sentences: what SC#3's goal-claim half
asks for; that this method covers the completeness and isolation halves while its sibling
`test_three_masters_each_render_shared_children_once` covers the shared-child occurrence counts and
resolved heading levels; and that neither duplicates the other. Cross-referencing the sibling by name
is required — it is what stops a later reader from deleting one as redundant.

**Step 4 — record the liveness observation.** Once the method is green, prove it is not vacuous. Take
the absence assertion (the marker that must occur on zero pages of `manual3.pdf`), invert it in a

capture the FAILING transcript. That transcript is the proof the page-scan detector fires on a real
violation. Restore the committed file to the correct assertion and confirm it is green again. Task 2
records the transcript.
