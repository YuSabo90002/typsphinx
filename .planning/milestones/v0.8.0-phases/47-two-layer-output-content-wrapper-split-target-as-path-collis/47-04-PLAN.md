Migrate corpus group A — 17 test modules and 21+6+7 fixture projects — from the pre-split single-file
output shape to the two-layer shape, and de-collide every group-A fixture target.

Purpose: this is one quarter of the largest single cost in the phase and one the research did not
size. Measured on the current tree: **87 of the 100 fixture projects under `tests/fixtures/` configure
a target whose resolved path equals its own docname's content path** (the overwhelmingly common
`("index", "index", ...)` shape), and **68 test modules with 591 code-level `index.typ` / `index.pdf`
references** read the pre-split file shape. Once 47-02 lands, those fixtures write a wrapper and a
content file onto one physical path; once 47-09 lands, they fail the build outright. Binding
constraint #8 requires the phase to close green, so this migration is not optional and cannot be
deferred to a later phase.

Output: group A green against the post-split emitter, with every fixture de-collided.
</objective>

## Migration rules (authority: `47-EXPECTED-STRUCTURE.md` `## Corpus migration rules`)

| Rule | Assertion class | Reads today | Reads after the split | Why |
|------|-----------------|-------------|------------------------|-----|
| R1 | translator body markup, marker strings, code-mode leakage | `index.typ` | `index.typ` (content) — **UNCHANGED** | the translated body is emitted into the content file |
| R2 | template application: a `_template.typ` import, a `#show:` application, title/author parameters, the outline call | `index.typ` | `<target-stem>.typ` (wrapper) | the template application moved to the wrapper |
| R3 | `typst.compile()` of a complete document | `index.typ` | `<target-stem>.typ` (wrapper) | only the wrapper is a complete document |
| R4 | a `-b typstpdf` produced PDF | `index.pdf` | `<target-stem>.pdf` | `typstpdf` compiles wrappers only |
| R5 | toctree `include()` emission | `index.typ` | `index.typ` (content) — **UNCHANGED** | toctrees are emitted where the doctree is translated |

**Fixture de-collision rule.** For each fixture in this plan's lists, read its `conf.py`
`typst_documents` and compute each entry's resolved target stem (strip only a literal trailing
`.typ`). If that stem `casefold()`-equals the entry's own docname, equals another docname in the same
fixture, equals `_template`, or equals another entry's stem, change element `[1]` to `"master.typ"`.
Where the fixture's own purpose names its target (its `conf.py` comment says the target value is
load-bearing), choose a purpose-specific distinct name instead and record the reason in that comment.
Never change elements `[0]`, `[2]`, `[3]` or `[4]`.

**Do not touch** `tests/fixtures/derived_docname_collision_gate/`,
`tests/fixtures/derived_template_collision_gate/`, `tests/fixtures/explicit_docname_collision_gate/`
or `tests/fixtures/explicit_template_collision_gate/` — those four are SUPPOSED to collide and belong
to plan 47-09.
