<objective>
Put `gsd/v0.8.0-multi-master-composition` on `origin` and prove it with a completed CI run that
includes the Windows and macOS lanes.

Purpose: milestone invariant #5 and binding constraint #2. Both defects that cost v0.7.0 — a
Windows-only encoding failure and an unexercised release job — came from the branch never being
pushed until the end, and the discipline paid immediately in v0.7.1 when a Windows-only path
separator defect surfaced during Phase 46 instead of at the release PR. This milestone raises the
stakes further: research Pitfall 5 measured that the case-insensitive-filesystem collision gap is
structurally invisible on Linux, so BLD-04's physical consequence has exactly one observation point
and it is the Windows and macOS lanes.

The branch exists locally with planning commits and has NOT been pushed. It reaches `origin` here.

Output: the branch on `origin`, a completed CI run over it including both lanes, and
`47-CI-EVIDENCE.md` recording the measured result.
</objective>
