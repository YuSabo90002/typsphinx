## Migration rules (authority: `47-EXPECTED-STRUCTURE.md` `## Corpus migration rules`)

| Rule | Assertion class | Reads today | Reads after the split | Why |
|------|-----------------|-------------|------------------------|-----|
| R1 | translator body markup, marker strings, code-mode leakage | `index.typ` | `index.typ` (content) — **UNCHANGED** | the translated body is emitted into the content file |
| R2 | template application: a `_template.typ` import, a `#show:` application, title/author parameters, the outline call | `index.typ` | `<target-stem>.typ` (wrapper) | the template application moved to the wrapper |
| R3 | `typst.compile()` of a complete document | `index.typ` | `<target-stem>.typ` (wrapper) | only the wrapper is a complete document |
| R4 | a `-b typstpdf` produced PDF | `index.pdf` | `<target-stem>.pdf` | `typstpdf` compiles wrappers only |
| R5 | toctree `include()` emission | `index.typ` | `index.typ` (content) — **UNCHANGED** | toctrees are emitted where the doctree is translated |

**Fixture de-collision rule.** For each fixture, read its `conf.py` `typst_documents` and compute
each entry's resolved target stem (strip only a literal trailing `.typ`). If that stem
`casefold()`-equals the entry's own docname, another docname in the same fixture, `_template`, or
another entry's stem, change element `[1]` to `"master.typ"` — or, where the fixture's own purpose
names its target, to a purpose-specific distinct name whose reason is recorded in that fixture's
`conf.py` comment. Never change elements `[0]`, `[2]`, `[3]` or `[4]`.

**Do not touch** the four CR-01 collision fixtures — they belong to plan 47-09.
