<objective>
Close the one root cause behind the three open gaps (NIX-02, NIX-03, NIX-04; `64-REVIEW.md` CR-01).
Pillow's `_imaging` carries a bare `NEEDED libz.so.1`. The FHS rootfs has none, and uv-managed CPython
links zlib statically, so nothing in the process ever maps it. This plan adds `targetPkgs = p: [ p.zlib ]`
to `fhsRun`. It proves the edit is the minimum by auditing the DT_NEEDED closure of the environments it
actually provisions, before and after, rather than by watching one test turn green. It then sweeps the
full suite, `tox -e py312` and `tox -e cov` as diagnostics, so that any second environment-caused
failure surfaces before the maintainer is asked to relaunch. Finally it re-binds NIX-06, NIX-07 and
NIX-08 on the final flake.
