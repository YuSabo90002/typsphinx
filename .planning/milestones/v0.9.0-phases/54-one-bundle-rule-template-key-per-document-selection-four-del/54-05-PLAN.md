<objective>
Delete the four mechanisms the one bundle rule makes redundant, and migrate the assertions that
were watching them.

Purpose: PROJECT.md's framing of this milestone is that unifying the route makes these four
collapse into deletions rather than additions — the phase is half deletion by identity, and a plan
that only adds has not planned it. Concretely: the builder still writes a shared template file at
the output root that nothing imports any more; it still runs a parallel asset-copy path with three
global early returns that the per-key driver has superseded; and it still carries an explicit
asset-list mode whose configuration value this milestone removes. Every one of those is now dead
weight that a reader would reasonably mistake for live behaviour.

Output: five methods gone from `builder.py`, one call site gone from `prepare_writing()`, one call
site gone from `finish()`, one test module gone, and the remaining output-tree assertions migrated
to the per-key bundle layout.
</objective>
