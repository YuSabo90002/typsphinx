## Measured findings this plan is built on (do not re-derive)

All four were measured this planning session against the current tree.

1. **BLD-07's collision reproduces end to end on a real build.** With docnames `index`, `c`, `a`,
   `a#0>b`, `b#0>c`, where `index` toctrees `c`, `a`, `a#0>b` in that order, `a` toctrees `b#0>c`, and
   `a#0>b` toctrees `c`: `sphinx-build -b typstpdf` exits 0, `manual.typ` publishes the array
   `("index#0>c", "index#0>a", "a#0>b#0>c", "index#0>a#0>b",)`, and BOTH `a.typ` and `a#0>b.typ` emit a
   guard on the identical key `a#0>b#0>c`. The `a#0>b` to `c` edge is DARK — `c` was already claimed by
   `index` — yet its guard fires because its key collides with the live `a` to `b#0>c` edge key. The
   compiled `manual.pdf` therefore contains `c`'s body marker **twice** (3 pages).
2. **The greater-than character cannot appear in a committed filename.** It is reserved on Windows, so
   a committed fixture would break `git checkout` on the `windows-latest` CI lane for the whole
   repository. The number sign is legal on Windows; the greater-than sign is not. A collision
   nevertheless REQUIRES a greater-than in a docname: with only number signs present the key
   `<parent>#<occurrence>><child>` still has exactly one greater-than, so parent and child stay
   separable and no two triples can collide. Hence the runtime-built, Windows-skipped gate.
3. **The proposed escaping is injective.** Brute-forced over 640,000 `(parent, child, occurrence)`
   triples drawn from the alphabet `a # > \ 0 1 "` with component lengths 0–3 and occurrences 0, 1, 2
   and 10: zero collisions with the escaping applied, versus a first collision at
   `('', '#0>', 0)` against `('#0>', '', 0)` — both `#0>#0>` — without it.
4. **Typst does not collapse the emitted escape.** Compiled against this repository's pinned
   `typst-py`: `"x\#y"` has length 4, `"x\#y"` does not equal `"x#y"`, and
   `"a#0>b\#0\>c"` equals neither `"a#0>b#0>c"` nor `"a\#0\>b#0>c"`. The backslash survives as an
   ordinary character in the string VALUE, which is what makes the two keys stay distinct inside the
   published state array at compile time.
5. **BLD-08's usable depth is far lower than 900.** `sys.getrecursionlimit()` is 1000; the deepest
   chain `derive_master_edge_keys` survives from a near-empty stack is 995; a 900-deep chain already
   raises `RecursionError` once roughly 100 caller frames sit above the walk. A real `sphinx-build` was
   measured at 11 caller frames above `derive_master_edge_keys`, and a pytest plus `SphinxTestApp`
   stack is deeper. `55-RESEARCH.md`'s proposed 900 is therefore **not safe** and is not used.
