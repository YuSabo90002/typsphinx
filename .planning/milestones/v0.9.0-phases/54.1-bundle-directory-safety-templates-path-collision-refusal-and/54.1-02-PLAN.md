<objective>
Close the documentation half of WR-01: stop every page under `docs/source/`, `README.md`, and every
runnable project under `examples/` from recommending that a Typst template live inside the directory
Sphinx's `templates_path` defaults to — and pin the result with an executable repo-wide assertion so
the recommendation cannot come back.

Purpose: the published documentation is the delivery mechanism of the WR-01 defect. A user who
copies a documented `conf.py` gets exactly the configuration plan `54.1-01` now refuses. Fixing the
code without fixing the docs would ship a release whose own quickstart no longer builds.

Output: a new gate module `tests/test_docs_template_layout_gate.py`; two renamed example template
directories; and updated configuration, prose, and tree diagrams across four documentation pages,
the root README, two example projects, and two stale test-file comments.

**Operational note for the executor / orchestrator — planned deletions.** This plan moves two
tracked files with `git mv`, which git records as a delete plus an add. This project's
`worktree.cleanup-wave` guard blocks any branch containing deletions, with no bypass. That is
expected here, not a failure: after the plan's own gates are green, verify the deletion scope is
exactly the two paths named below and merge the worktree branch by hand.
