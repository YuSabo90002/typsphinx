## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | pytest ≥8.4 (`pyproject.toml:35`); `sphinx.testing.fixtures` loaded as a plugin via `tests/conftest.py:12` |
| **Config file** | `pyproject.toml` (`[tool.pytest.ini_options]`, `pyproject.toml:75-84`) |
| **Quick run command** | `uv run pytest tests/test_<module>.py -x` |
| **Full suite command** | `uv run pytest tests/ -q` |
| **Estimated runtime** | ~110 seconds full suite (Phase 54 measured baseline: `1270 passed, 5 skipped in 109.29s`) |

**Worktree note (CLAUDE.md, standing execution mode):** every command above runs via `uv run`
inside the executor's own worktree, provisioned first with
`env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev`. Without that, pytest imports the
unchanged main-tree package and gates stay RED after a correct fix.

**Known pre-existing failure class (NOT a regression from this phase):** the 7 failing tests in
`tests/test_state_guard_shapes_gate.py` (they read an archived `.planning/` path). Recorded in
`.planning/phases/53-template-registry-foundation/deferred-items.md`; predates Phase 53. "Full suite
green" for this phase means green *modulo exactly these 7*, and any executor reporting them as new
RED is misreading the baseline.

## Sampling Rate

- **After every task commit:** Run `uv run pytest tests/test_<touched_module>.py -x`
- **After every plan wave:** Run `uv run pytest tests/ -q`, plus the three CI-matching gates —
  `uv run black --check .`, `uv run ruff check .`, `uv run mypy typsphinx/`
- **Before `/gsd-verify-work`:** Full suite green (modulo the 7 named above), plus a real build of
  this repository's own dogfooding project in both builders — `tox -e docs-html` and
  `tox -e docs-pdf` — confirming the NON-colliding shape (`docs/source/conf.py:45` sets
  `templates_path`, `:96` sets `typst_template = "_typst/custom_template.typ"`) still builds
- **Milestone invariant #9:** `git ls-remote --heads origin gsd/v0.9.0-per-document-templates`
  confirming the milestone branch is pushed (paid every phase since Phase 43)
- **Max feedback latency:** 120 seconds
