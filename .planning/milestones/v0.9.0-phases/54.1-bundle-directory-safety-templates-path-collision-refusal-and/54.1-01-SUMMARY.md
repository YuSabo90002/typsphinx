# Phase 54.1 Plan 01: Tracer — Pre-Write templates_path Collision Refusal Summary

**A used registry key whose resolved template bundle directory collides with Sphinx's `templates_path` now refuses the build with an `ExtensionError` before any `.typ` file is written, closing WR-01's runtime half.**

## Accomplishments
- `_paths_related()` — a three-way is/contains/is-contained-by path predicate in `typsphinx/builder.py`, generalizing `template_registry._violates_conf17()`'s `commonpath()` idiom to a symmetric containment test, case-folded via `TypstBuilder._collision_key()`.
- `TypstBuilder._validate_used_template_paths()` — a pre-write validator called from `write()` immediately after `_validate_registry_key_references()` and before `prepare_writing()`, so a collision leaves zero `.typ` files on disk. Derives the checked key set from every usable `typst_documents` entry (including synthesized ones), reproduces `_copy_used_template_bundles()`'s per-key `TemplateEngine` resolution to obtain the RESOLVED bundle path, skips package-alone keys and `resolution.source == "default"` bundles, and accumulates every colliding key into one `sorted()`-ordered, byte-identical `ExtensionError`.
- A real `sphinx-build` subprocess gate (`tests/test_templates_path_collision_gate.py`) proving both the refusal and the "zero `.typ` files after refusal" property, recorded RED against the pre-fix tree before any production code changed.

## Decisions Made
- Case-folded `_paths_related()`'s two path operands through `TypstBuilder._collision_key()` (Claude's Discretion #2, decided per the plan's explicit instruction) rather than following `_violates_conf17()`'s non-folded precedent — matches `_collision_key()`'s own stated Linux-CI rationale.
- `templates_path` entries resolved against `self.srcdir` (not `self.confdir`); the `-c` confdir gap is named explicitly in `_validate_used_template_paths()`'s docstring, matching this codebase's convention of stating known scope limits inline.
- A used key whose `TemplateEngine.resolve_template()` resolution has `source == "default"` is exempted from the containment test (packaged-default bundles live inside the installed Python package, never under `srcdir`).
- Declared-but-unreferenced registry keys stay unchecked pre-write, per the plan's "do not widen" recommendation — the checked key set is reference-derived, matching `_validate_registry_key_references()`'s own scope.
