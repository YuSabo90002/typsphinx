## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| maintainer-authored `conf.py` → `TypstBuilder.write()` | `templates_path`, `typst_template`, `typst_document_templates` cross into path arithmetic and output-path derivation. Trusted-but-unreviewed input: not attacker-controlled, but capable of directing what the build publishes. | Filesystem paths (config values) |
| `TypstBuilder.write()` → `<outdir>` | Every content and wrapper `.typ` file is written here. A guard running after this point cannot un-write what it finds. | Generated Typst markup |
| `TypstBuilder.finish()` → `<outdir>/_template/<key>/` | Build output is a public artifact (published to Read the Docs, attached to GitHub Releases). Anything copied here leaves the maintainer's machine. | Whole template bundle directories |
| published documentation → a user's `conf.py` | Docs are copy-paste input to a maintainer's configuration; a recommendation published here becomes configuration in someone else's repository. | Recommended directory layouts |
| repository tree → the executable doc gate's search set | Gate scope is derived at run time from three roots; anything added under them later is automatically in scope. | Policed file set |
| this release → downstream v0.8.x projects | A refusal introduced here breaks builds that work today; the CHANGELOG is the only channel for that migration. | Breaking-change announcement |
