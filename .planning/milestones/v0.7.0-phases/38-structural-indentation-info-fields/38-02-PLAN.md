## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.rst` docstring / field-body source → translator | Author-controlled build-time text that reaches an emission site through the escaping boundary |
| translator → emitted `.typ` → `typst.compile()` | Where an unescaped or mis-composed leaf emission becomes a build fatal or a lost hyperlink |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
