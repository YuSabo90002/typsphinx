## The three landmines RESEARCH found in this extraction — read before writing code

1. **Pitfall 2 — the predicate must be silent.** `opens_wrapper`'s computation and the
   cross-document degrade-to-text `logger.warning` are fused into one code path today. D-06 moves the
   *judgement*; the **warning stays exactly where it is** in `visit_reference`'s existing branch. If
   the predicate re-derives `degrade_xref_to_text` non-silently, the warning double-fires per degraded
   reference. The predicate returns booleans and labels only — no logging, no side effects.
2. **Pitfall 3 — `next_is_target` has TWO consumers in `visit_reference`, not one.** The D-14
   eligibility gate uses it, and so does the pre-existing target-attachment markup wrap that fires
   whenever the next sibling is a target regardless of `ids`/`opens_wrapper`. That second consumer
   predates D-14 and is untouched by this phase. The predicate's return value must expose
   `next_is_target` so both consumers read one value computed once.
3. **Pitfall 4 — do not build a RED around Route A.** `_find_citing_reference` only ever returns a
   candidate whose own `ids` already contains the `refid` being searched for, so `ids` is non-empty
   by construction for every node `visit_citation` passes in. Keeping the `ids` check in the predicate
   is correct defensive code (the contract could change later) and the invariant test covers it as a
   parametrized case — but it is not a demonstrable bug today and no RED is built on it. Record its
   unreachability in the evidence file per D-01's "a negative result is exactly as valuable as a
   positive one".

Additionally: `visit_reference`'s downstream branches consume `xref` and `degrade_xref_to_text`
directly (the `elif xref is not None:` branch and its `if degrade_xref_to_text:` sub-branch). Because
D-06 moves the derivation into the predicate, those two values are returned by the predicate too —
otherwise `_resolve_xref_docname` would run twice per reference and the drift would simply move
downstream instead of upstream.
