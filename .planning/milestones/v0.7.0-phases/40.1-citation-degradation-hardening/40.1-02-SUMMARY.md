## Decisions Made

- **G2 (fix stays narrow):** one literal disjunct added to the existing `isinstance` check, no general "emits nothing" predicate and no new helper method. Rationale (three points, recorded in `40.1-02-PLAN.md` and mirrored into the docstring): (1) `40.1-CONTEXT.md`'s `<deferred>` section explicitly defers generalising the emit-nothing concept beyond citations; (2) the general claim would be false as written — `visit_target`'s ids-falsy branch still writes a separator and sets `list_item_needs_separator` inside a list item, strictly weaker than `comment`'s unconditional `SkipNode`; (3) a general predicate would need to be correct for every node type to earn its name, while this disjunct only needs to be correct for the one type that was measured end-to-end.
- **D-01 provenance for WR-02:** all five plausible RST shapes for the minimal single-blocker topology were attempted (documented in `40.1-RESEARCH.md` and carried verbatim into `40.1-GATE-EVIDENCE-02.md`) and none reproduces it — docutils' target-chaining transform (0.22.4) never leaves a solitary ids-less target; the chain's terminal member always keeps a real id and sits in the same gap, independently breaking the run. This is a negative result of independent value, not a bare "not reproducible" — the RED therefore uses the assembled-doctree harness.
