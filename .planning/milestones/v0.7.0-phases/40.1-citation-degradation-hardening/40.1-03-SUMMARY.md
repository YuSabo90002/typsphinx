# Phase 40.1 Plan 03: WR-03 D-14 Shared Anchor Predicate Summary

**Deleted the duplicated D-14 eligibility judgement by extracting one shared, silent predicate (`_ReferenceAnchorDecision` / `_reference_anchor_decision`) that both `visit_reference` and `visit_citation`'s backref loop now consult -- closing a second route to WR-01's dangling-label compile fatal, and returning the anchor label itself (not just the boolean) so the link target and the attached anchor come from one expression.**

## Accomplishments

- Closed `40-REVIEW.md`'s WR-03 (ROADMAP SC#3): the D-14 citing-site anchor eligibility judgement, previously written independently in `visit_reference` (three conditions) and `_citing_reference_has_own_anchor` (one condition, assuming the other two), is now derived in exactly ONE place -- `TypstTranslator._reference_anchor_decision` -- consulted by both sites. `_citing_reference_has_own_anchor` is DELETED entirely (D-05), not kept as a delegator.
- Recorded D-08's full two-route attempt list in `40.1-GATE-EVIDENCE-03.md`: Route A (`ids` empty) is a control-flow fact about `_find_citing_reference`'s own matching logic, verified by reading the code rather than a build measurement; Route B (`opens_wrapper` false via `degrade_xref_to_text`) was attempted against a real two-document build and found unreachable (`backrefs` never names a cross-document citing site's id, and a same-document citing reference never carries `refuri`). Both routes unreachable -> the RED hand-assembles a doctree via `_make_citing_reference` that violates BOTH invariants at once.
- The predicate derives its own inputs from the node plus builder state (D-06) rather than accepting three pre-computed booleans, and returns the anchor LABEL as well as the boolean (D-07) -- so `visit_citation`'s appended backref target is now `decision.anchor_label`, the SAME expression `visit_reference` used to attach the anchor, rather than a second independent `_namespace_label(docname, refid)` call.

- Added two invariant backstop tests WITH the fix (not the RED, per `40.1-CONTEXT.md`'s assumption-delta decision): a four-case parametrized test tying `decision.eligible`/`decision.anchor_label` to what was actually emitted, and the xref-resolution/warning-count guard above.

## Decisions Made

- **D-05 applied verbatim (delete, don't delegate):** `_citing_reference_has_own_anchor` has exactly one caller (grep-confirmed), and the plan's Claude's-Discretion note left "delegator vs. delete" open -- delete was chosen because a thin delegator would still leave a second named symbol a future edit could accidentally diverge from, while deletion makes the single-derivation-point invariant structurally enforced rather than merely documented.
- **D-08 provenance for WR-03:** both routes attempted this session per `40.1-CONTEXT.md`'s D-01 discipline. Route A recorded as a pure control-flow fact (independent of Sphinx/docutils version); Route B recorded against a real two-document build's verbatim doctree dump (carried from `40.1-RESEARCH.md`'s own session measurement, per this evidence file's established convention of not re-running an already-reproduced real build). Verdict: directly-assembled doctree for both, per D-01's "real build whenever available, fallback otherwise."
- **`next_is_target`'s parentless default (documented divergence, not silently resolved):** the deleted `_citing_reference_has_own_anchor` returned `True` ("no target follows") for a parentless node; the new predicate returns `False`, matching `visit_reference`'s own pre-existing lookahead. The predicate's docstring states explicitly that `visit_reference`'s form is authoritative and that this divergence was itself an instance of the WR-03 defect class being closed -- not a new decision requiring owner sign-off, since neither production node in this repository's corpus is ever parentless (only test harnesses construct one).
