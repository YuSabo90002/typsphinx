## Claude's-Discretion items — decided here, not deferred to the executor

CONTEXT.md § "Claude's Discretion" left two questions open. Both are decided now, with rationale, so
the executor implements a decision rather than making one.

### G1 — a skipped back-reference degrades **SILENTLY** (no Sphinx warning)

Decision: neither arm of the backref filter warns. The `ref_node is None` arm this plan adds is
silent, matching the already-shipped `_citing_reference_has_own_anchor`-returns-`False` arm beside it.

Rationale:

1. The reproducible real-build trigger is `.. only:: <tag>` around a citing `[Label]_` — a
   legitimate, common documentation pattern, not an authoring error. Dropping the back-reference
   marker for a citing site that genuinely is not in the output document is the *correct* answer,
   and warning on correct input is noise. The repository's docs builds do not pass `-W` today
   (checked: no `-W` / `warningiserror` in `tox.ini`, `.github/workflows/`, or `docs/`), but a
   downstream project that does would have correct sources turned into build failures.
2. Warning on only one of the two arms of the same `if` would reintroduce exactly the asymmetry
   WR-01 is about. Warning on **both** arms would change already-shipped Phase 40 behaviour that no
   decision in this phase authorises changing.
3. The footnote precedent (`visit_footnote_reference`'s dangling-target guard, which warns then
   skips) does not transfer: it fires when the *target* is missing — a genuine authoring error. Here
   the target (the citation definition) exists; only a back-*reference* marker pointing at a
   non-existent citing site is dropped.

Obligation that comes with this choice (CONTEXT.md states it explicitly): because `visit_citation`
enumerates the **filtered** list, dropping a backref changes the marker's *shape* under Phase 40's
D-03. **The emitted shape for every degraded citation is therefore asserted, not left to chance** —
the fixture below deliberately carries all three transitions (3→2, 2→1, 1→0) and Task 2 asserts each.

### G2 — WR-02's fix stays **NARROW** (decided in full in plan `40.1-02`; recorded here for coherence)

Only the ids-less `nodes.target` case is added to `_citation_run_neighbour`'s existing skip list. No
general "sibling that emits nothing" predicate. Full rationale lives in `40.1-02-PLAN.md`.
