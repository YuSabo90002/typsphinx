## Execution environment (MANDATORY — worktree-isolated execution is this repo's standing mode)

Before running anything, detect isolation with `test -f .git` (a FILE, not a directory, means an
isolated worktree). In a worktree, provision the worktree's own environment FIRST with
`env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev`, then run every subsequent
