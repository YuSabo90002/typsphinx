<objective>
Stand up the two geometric gates — SIG-07 (a long fully-qualified signature stays inside the right
text margin) and SIG-09 (a signature and the first line of its body are not split across a page
break) — against the untouched translator.

Purpose: both requirements are about *layout*, and the project's usual assertion tools are wrong for
them. Research measured that the real corpus never overflows at production width (so a corpus fixture
cannot go RED) and that `pypdf`'s per-glyph position extraction is unusable on Typst PDFs (so
bounding-box assertions are out). This plan builds the two gates that actually can fail.

Output: two fixture projects, two gate modules, and `37-GATE-EVIDENCE-03.md`. This plan does NOT
touch `typsphinx/`.
</objective>

|----------|-------------|
| `.rst` source → translator | Author-controlled build-time text |
| translator → emitted `.typ` string literal | Where unescaped text would become Typst syntax |
| emitted `.typ` → `typst.compile()` | Local compile of locally-generated source; no network |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-37-03 | Tampering | The SIG-07 probe concatenates a `context` measurement block onto the emitted `.typ` before compiling | low | mitigate | The probe suffix is a fixed, test-authored literal containing no fixture-derived text; the emitted `.typ` itself is prepended/appended to but never edited, so the artifact under test stays the translator's own output. |
| T-37-02 | Information disclosure | none — no new network, file, subprocess, or dependency surface | low | accept | Test-only plan; subprocesses are `sys.executable -m sphinx` and in-process `typst.compile()` against local fixtures. |

ASVS L1: V5 Input Validation only, already mitigated project-wide by `escape_typst_string`. No
high-severity threat. No package installs, so the package-legitimacy gate does not apply.
