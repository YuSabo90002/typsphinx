<environment_setup>
NixOS sandbox. Provision the worktree before any python command, and run everything through `uv run`:

```bash
env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev
for t in uv ruff; do [ -x "$(command -v $t)" ] && ln -sf "$(command -v $t)" ".venv/bin/$t"; done
```

The `ln -sf` shim is required: `uv sync` installs generic-linux ELF `uv`/`ruff` wheels that NixOS
cannot exec. With it applied a worktree suite is byte-identical to the main tree, so ANY
environmental failure is a provisioning miss, not expected noise.

Real `typst.compile()` works here, including `format="png"`, which is how the visual check below is
performed. Fixtures must invoke Sphinx as `sys.executable -m sphinx`, never `["uv","run","sphinx-build"]`.
</environment_setup>
