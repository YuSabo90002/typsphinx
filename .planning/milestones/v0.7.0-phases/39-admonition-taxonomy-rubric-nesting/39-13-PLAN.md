<environment_setup>
Worktree isolation is this project's STANDING execution mode (`CLAUDE.md` § "Worktree-isolated
execution"). Before running ANY command in this plan:

1. `env -u VIRTUAL_ENV -u UV_PROJECT_ENVIRONMENT uv sync --extra dev`
2. `for t in uv ruff; do [ -x "$(command -v $t)" ] && ln -sf "$(command -v $t)" ".venv/bin/$t"; done`
3. Run everything through `uv run` from then on.

Step 2 matters most in this plan: the corpus gate shells out to a subprocess, and `.venv/bin/uv`
installed by the sync is a generic-linux ELF that exits 127 under the NixOS stub loader while
shadowing the correct binary on PATH for that child. Both shims are required, resolved via
`command -v` BEFORE any `.venv/bin` entry exists on PATH. Measured during Phase 39: 45 failures with
exit 127 before the `uv` shim, 763/764 after (`.planning/STATE.md` § "Operator Next Steps").
</environment_setup>
