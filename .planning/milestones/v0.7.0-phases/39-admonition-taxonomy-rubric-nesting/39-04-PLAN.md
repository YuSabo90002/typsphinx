fixture, and a pipeline smoke test. This plan does NOT produce the committed UAT artifact — that must
be rendered from post-fix code and belongs to plan 39-07. This plan does NOT touch `typsphinx/`.

checkpoint out of an implementation plan. It is deliberately not followed here, for a reason recorded

worktree syncs from a `pyproject.toml` that predates the edit. Splitting would satisfy the heuristic
and break both constraints.
