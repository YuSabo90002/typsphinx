<objective>
Build the ADM-05 invariance guard: a real `-b typstpdf` fixture and a `pypdf` geometry module proving
that a rubric's left edge equals the left edge of the description body containing it, at two nesting
levels, and that a rubric outside any description body sits flush with ordinary top-level text.

Purpose: 39-CONTEXT.md measured that ADM-05 **already holds** — Phase 38's `pad` wrapper around
`desc_content` carries the rubric structurally, and `visit_rubric` performs no indent logic of its own.
A GATE-01 RED cannot be recorded against pre-phase code for a property that is already true, which is
exactly the situation Phase 36's SC#3 hit and resolved the same way. D-12 therefore converts SC#3's
indentation claim into an invariance guard, and the phase's classic RED comes from plan 39-02's folded
defect instead. This plan writes the guard.

Output: `tests/fixtures/rubric_indent_invariance_gate/`, `tests/test_rubric_indent_invariance.py`, and
`39-GATE-EVIDENCE-03.md` recording the guard green against a named pre-fix commit. This plan does NOT
touch `typsphinx/`.
</objective>
