<objective>
Record the GATE-01 RED for gap G-39-1: the red family stops being one collapsed function. Extend the
existing bucket gate so the danger, attention and error types are asserted as three pairwise-distinct
gentle-clues functions, add the generalized red-family invariant, and add a new gate proving the
Sphinx locale catalog title still beats gentle-clues' own per-id default for both newly-used function
ids in both the English and Japanese catalogs.

Purpose: G-39-1 reverses locked decision D-03 after a live A/B/C render comparison. The shipped code
routes all three red-family types through the error function and compiles fine while doing so, so RED
here is a structural region-scoped mismatch, exactly as this milestone's amended GATE-01 bar requires.
The catalog-title half is the gap's highest-risk regression: gentle-clues 1.3.1 supplies its own
linguify title for every predefined id, so the moment attention starts riding the memo function, a
lost title argument would silently rename it.

Output: an extended `tests/test_admonition_bucket_render_gate.py`, a new
`tests/test_admonition_locale_title_precedence_gate.py` with its two-locale fixture project, corrected
annotations in the shared admonition fixture, and `39-GATE-EVIDENCE-05.md` recording the RED verbatim
against a named commit. This plan touches NO file under `typsphinx/` — plan 39-11 owns the routing
change that flips this RED.
</objective>
