<objective>
Prove, end to end and against a real compile, that a document reached through a `toctree` nests one
level below its parent and that nested toctrees compose — then land the two-site repair that makes it
true.

This is the phase's tracer slice: it touches every layer TOC-01 modifies (a Sphinx project source
tree, `sphinx-build -b typst`, the emitted `.typ`, `typst.compile()`/`typst.query()`, and both
`typsphinx/translator.py` emission sites) on the single thinnest path, and it carries a real runnable
end-to-end verify rather than per-layer unit assertions. The gate it introduces is production-quality
and permanent — it is the GATE-01 regression fixture SC#5 requires, not a scratch probe.

Purpose: SC#1, SC#2, SC#4 and SC#5 all rest on one measurement — the *resolved* heading level of a
compiled multi-document project. Making that measurement first, recording it RED, and only then
editing `typsphinx/` is what turns "the outline nests now" from an assertion into evidence.

Output: a new permanent render gate, the two-part repair in `visit_title` and `visit_toctree`, and
`44.1-GATE-EVIDENCE-01.md` carrying the pre-fix RED, the part-1-only intermediate measurement that
justifies D-07, and the post-fix GREEN.

This plan owns the phase's scope fence. Two prohibitions ride on it (see `must_haves.prohibitions`):
the D-03 template fence, and the ban on transcribing any figure that was not measured in this
session. Plans 02 and 03 carry the anti-vacuity prohibition for the guards they rewrite.
</objective>

<assumption_delta_decision>
The deterministic scan reported `detected: true` (`kind: pluralization`). It is a real signal, not a
false positive, and this is the identity model it names:

- **The noun that is now primary:** the *include site's ambient heading offset*, not the included
  file's own offset. An included document's `.typ` is one file on disk that any number of masters may
  reach at differing depths; the offset therefore belongs to the composition context, not to the file.
- **Decision: `promote`.** The relative expression (`heading.offset + 1`, evaluated at layout time per
  include site) is promoted to the primary representation, and the absolute per-file value is not kept
  alongside it — it is removed. This is exactly D-07's second, stronger argument: with an absolute
  offset there is no value a shared file can carry that is correct for every master that includes it,
  so "add alongside" would have preserved a representation that is ill-defined rather than merely
  incomplete.
- **Suggested invariant test (NOT planned, and why):** the natural companion is "one shared `.typ`
  resolves correctly from every master that includes it, at differing depths" — the two-master
  asymmetric-depth case measured in 44.1-CONTEXT.md `<specifics>` item 9. It is **not** added to this
  phase because deferred defect A (`_included_docnames` is reset per build rather than per master,
  44.1-CONTEXT.md `<deferred>`) silently drops a shared document from every master but the
  first-written one. Such a test would fail for a reason unrelated to TOC-01. Recorded here as an
  explicit assumption: the promotion is correct at the emission layer and is proven so by SC#1/SC#2,
  but its multi-master pay-off cannot be asserted until defect A is repaired.
</assumption_delta_decision>
