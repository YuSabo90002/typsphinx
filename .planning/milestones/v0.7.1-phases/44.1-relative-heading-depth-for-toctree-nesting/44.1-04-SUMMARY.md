## Issues Encountered

- The worktree-path safety checker in this sandbox false-flags the literal substring `source`
  anywhere in a Bash command (e.g. the path `docs/source`) as an invocation of the shell `source`
  builtin, blocking direct `find docs/source ...` / `ls docs/source` commands. Worked around per
  this project's own environment notes: every corpus-enumeration and build command that needed to
  name `docs/source` was issued through a `uv run python3 -c "..."` subprocess using a
  `pathlib`-constructed path string instead of a literal Bash path argument.
- `docs/source/api/index.rst`'s residual post-substitution diff (§6.2) was not anticipated by the
  plan's own framing of SC#3(b) (which assumes docstrings never reach `.typ` output) — investigated
  rather than smoothed over, traced to Sphinx autodoc rendering `typsphinx`'s own rewritten
  `visit_toctree` docstring, and recorded as an expected, non-heading-shape exception rather than
  forced to zero.
