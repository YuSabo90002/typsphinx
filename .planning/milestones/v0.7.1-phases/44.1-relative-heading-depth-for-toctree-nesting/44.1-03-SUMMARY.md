# Phase 44.1 Plan 03: Test Migration for the Two-Part D-07 Repair (5 files outside test_topics.py) Summary

**Re-derived the SC#6 site census by repo-wide grep (correcting 44.1-CONTEXT.md's undercounted
D-04 addendum), migrated all 7 of plan 01's measured worklist node ids that belong to this plan's
five files, regenerated the byte-compared golden fixture from a real build, and added the
empty/single-entry toctree edge assertions — every rewritten assertion proved failing against
plan 01's pre-fix anchor commit inside this plan's own worktree.**

## Performance

- **Duration:** ~75 min
- **Tasks:** 3 (3 commits, one per task)

## Accomplishments

- Re-derived the phase's SC#6 site census with three repo-wide greps run in this session
  (`heading(level:`, `set heading(offset: 1)`, and the wider `heading(offset` sweep), confirming
  `typsphinx/` is already fully migrated by plan 01 and classifying every hit in this plan's five
  files into one of four proof-obligation classes (assert-participating positive, assert-
  participating regex, byte-compared fixture, non-assert-participating).
- Recorded a per-file divergence table against 44.1-CONTEXT.md D-04's addendum: the addendum named
  only 2 sites in `tests/test_toctree_requirement13.py`, but a third assert-participating test
  (`test_toctree_single_entry_with_single_block`) and one extra site in `tests/test_translator.py`
  (`test_toctree_generates_outline`) were also measured — matching GATE-EVIDENCE-01's own flagged
  extra exactly.
- Migrated `tests/test_translator.py`'s four assertions (three heading-argument literals, one
  toctree-offset literal), leaving the two keyword-agnostic table-caption guards untouched.
- Migrated `tests/test_toctree_requirement13.py`'s substring and exactly-once-regex assertions to
  the new two-part `context { set heading(offset: heading.offset + 1) }` literal, preserving the
  exactly-once semantics (proved by a measured pre-fix count of 0, post-fix count of 1). Rewrote
  every docstring/comment quoting the old literal. Strengthened the empty-entries test to assert
  `pytest.raises(nodes.SkipNode)` plus neither the scope opener nor `include(` present, and the
  single-entry test to count `include(` occurrences instead of merely checking membership.
- Measured `tests/test_integration_multi_doc.py`'s disjunctive assertion directly (not assumed):
  it passes against both the pre-fix and post-fix literal shapes and cannot discriminate them —
  documented that fact in the test's own docstring rather than relying on it as a silent guard.
- Updated `tests/test_pdf_render_gate.py`'s hand-built pre-fix reconstruction's heading argument
  name for system-wide consistency, leaving the two sentinel assertions and constants that
  actually gate that test untouched.
- Regenerated `tests/fixtures/desc_rubric_decoupling_render_gate/golden.typ` from a real
  `sphinx-build -b typst` run of its own fixture (not hand-edited), confirmed a zero diff against
  the live build output, and confirmed the committed `git diff` is confined to the single heading
  argument line.
- Reverted `typsphinx/translator.py` to plan 01's pre-fix anchor commit (`9d279250648ba2be2ca77f
  072e8655e6d6a689e7`) inside this plan's own worktree and recorded 7 real pytest FAILUREs
  (covering all 8 assert-participating worklist rows) plus the golden-fixture failure with its
  unified diff — then restored the file byte-clean and re-confirmed plan 01's own gate (4 tests)
  is undisturbed.
- Applied and documented a `.venv/bin/uv` -> nix-store `uv` symlink workaround, without which
  `tests/test_integration_multi_doc.py`'s `uv`-subprocess integration tests fail with exit 127 in
  this NixOS worktree sandbox regardless of this plan's changes — and without which this plan's
  own flagged site (`L134`) would have stayed invisible, exactly as it was in GATE-EVIDENCE-01's
  45-failure environmental bucket.
