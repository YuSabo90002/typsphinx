## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Substring false-positive in a new key-absence assertion**
- **Found during:** Task 2, first `pytest` run
- **Issue:** `TestPartialParamsTemplateGate.test_auto_derived_and_element_keys_are_absent` checked `f"{key}:" not in region` for `key in ("title", ...)`. Since the fixture's own declared, correctly-emitted key is `subtitle:`, the bare substring check matched `"title:"` inside `"subtitle:"` and failed the test on a false positive — not a real leak.
- **Fix:** Replaced the substring check with a line-anchored regex (`re.search(rf"(?m)^\s*{re.escape(key)}:", region)`), matching only a key at its own named-argument position.
- **Files modified:** `tests/test_params_exclusivity_gate.py`
- **Verification:** `uv run pytest tests/test_params_exclusivity_gate.py -q` — 21 passed
- **Committed in:** `f9afce6` (Task 2 commit; the test module was not yet committed when the bug was caught, so no separate fix commit was needed)
