# 45.1-07: Cross-Page Contract Sweep

**Purpose:** the cross-page extension of plan 06's SC#2 emission-site enumeration
(`45.1-CONTRACT-ENUMERATION.md` Task 2). Plan 06 proved two-way agreement between
`typsphinx/writer.py` / `template_engine.py`'s emission sites and `templates.rst`'s published
nine-parameter contract — but only for `templates.rst`. It never read `configuration.rst`, so a
stale route-scope claim survived there, undetected, until `/gsd-audit-uat` and
`45.1-VERIFICATION.md` found it (CR-01). This document records the doc-set-wide sweep that
closes that hole, and the permanent guard (`tests/test_docs_contract_claims_gate.py`) that
replaces the one-shot manual enumeration going forward.

**Session:** 2026-08-10, this plan (45.1-07), Task 2.

## Why plan 06's SC#2 record did not catch this

`45.1-CONTRACT-ENUMERATION.md`'s "Task 2 — SC#2" section enumerates eight emission sites in
`writer.py`/`template_engine.py` and compares their contributable name set against exactly one
page: `docs/source/user_guide/templates.rst`'s "Standard Parameters" section. That comparison is
correct as far as it goes — `templates.rst` was rewritten (plan 05) to state the D-I rule
accurately, and plan 06 proved agreement between the code and *that page*. But
`docs/source/user_guide/configuration.rst`'s "Document Language" section publishes an
*independent* route-scope claim about the same `lang` parameter, and nothing in plan 06's SC#2
proof ever read it. That page still stated the pre-CONF-12 rule (`45.1-REVIEW.md` CR-01) until
Task 1 of this plan corrected it. The gap was a scoping gap in the *proof*, not a second code
defect — the code (`TemplateEngine.uses_bundled_default_template()`) has been correct since plan
03 (CONF-12).

## Method: bare scan, then human-reviewed page sets

`tests/test_docs_contract_claims_gate.py`'s `_page_makes_contract_claim()` runs a bare substring
scan over every `*.rst` under `docs/source/`: a page counts as publishing a contract claim when it
mentions at least one of the nine published parameter names as an RST inline literal (` ``lang`` `,
` ``title`` `, …) **and** at least one route/config token (` ``typst_template`` `,
` ``typst_package`` `, ` ``base.typ`` `, ` ``typst_elements`` `, or "bundled default"/"default
template" wording). This scan is deliberately over-inclusive — `typst_elements` is included
alongside the three literal template-route tokens because it is the config surface that carries
the allowlisted keys across pages, and a page merely *mentioning* the allowlist (without making a
live claim about current behaviour) still needs a human to look at it and decide, not a scanner
guessing on its behalf.

## Two directional conclusions, with concrete route sets

Five real `TemplateEngine` constructions (`ROUTE_CONFIGS`), covering the bundled default, an
explicit `typst_template`, a `<srcdir>/base.typ` shadow, `typst_package` alone, and
`typst_package` combined with an explicit `typst_template` (the CONF-12 adjacency edge no fixture
under `tests/fixtures/typst_lang_gate/` covers — see that directory's `package_no_lang/conf.py`
comment):

```
$ uv run python -c "
import sys; sys.path.insert(0, 'tests')
from test_docs_contract_claims_gate import (
    CODE_WITHHELD_ROUTES, CODE_AFFIRMED_ROUTES, ROUTE_CONFIGS,
    _reviewed_pages_text, _withheld_routes_claimed, _routes_affirmed,
)
print('route_configs:', sorted(ROUTE_CONFIGS))
print('code_withheld:', sorted(CODE_WITHHELD_ROUTES))
print('code_affirmed:', sorted(CODE_AFFIRMED_ROUTES))
pages = _reviewed_pages_text()
print('docs_withheld:', sorted(_withheld_routes_claimed(pages)))
print('docs_affirmed:', sorted(_routes_affirmed(pages)))
"
route_configs: ['bundled_default', 'explicit_template', 'srcdir_shadow', 'typst_package_alone', 'typst_package_and_typst_template']
code_withheld: ['typst_package_alone', 'typst_package_and_typst_template']
code_affirmed: ['bundled_default', 'explicit_template', 'srcdir_shadow']
docs_withheld: ['typst_package_alone', 'typst_package_and_typst_template']
docs_affirmed: ['bundled_default', 'explicit_template', 'srcdir_shadow']
```

**Direction 1 (nothing denied by the docs that the code actually does):** the docs' published
withheld-route set `{typst_package_alone, typst_package_and_typst_template}` equals the code's own
withheld-route set, computed by calling `TemplateEngine.uses_bundled_default_template()` on each of
the five constructions. Equal by `==`, not by containment.

**Direction 2 (nothing the code does goes unpublished):** the docs' published affirmed-route set
`{bundled_default, explicit_template, srcdir_shadow}` equals the code's own affirmed-route set.
Equal by `==`, not by containment.

**Both hold as of this session** (`TestLangRouteScopeClaimsMatchShippedPredicate`, all three tests
green — see the live gate output below).

## Forbidden-claim detector: fail-first proof against the real pre-fix text

`TestForbiddenClaimDetectorIsFailFirst` feeds `PRE_FIX_FALSE_CLAIM` — the verbatim two-sentence
claim `45.1-REVIEW.md` CR-01 quotes, taken from `git show d952a8f:docs/source/user_guide/configuration.rst`
(this plan's own base commit, before Task 1) — directly to `_classify_sentence()`, bypassing the
page walk entirely. The detector classifies `explicit_template` and `srcdir_shadow` as withheld
(routes the pre-fix text falsely denied `lang` on, which the shipped code has actually affirmed
since plan 03 / CONF-12) — proving the detector would have gone red against `configuration.rst` as
it stood before this plan, had the guard existed then.

## Summary

- Both of `45.1-VERIFICATION.md`'s `missing:` items are closed: the stale `configuration.rst`
  prose is corrected (Task 1), and the agreement proof now spans every claim-publishing page under
  `docs/source/`, enforced by a permanent, fail-first-proved test
  (`tests/test_docs_contract_claims_gate.py`) rather than a one-shot manual enumeration.
- The class of gap that produced this closure round — a contract claim published on a page the
  agreement proof never read — now fails automatically the next time it recurs, on any page under
  `docs/source/`, not only the ones a human happened to check this time.
