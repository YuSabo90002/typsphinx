Every one of these eight named arguments is auto-derived or `typst_elements`/`toctree_*`-sourced —

explicitly `{}`. This is exactly the additive-union defect D-B/D-D exist to close: an explicitly
empty `params` dict does not withhold anything under the pre-fix `render()` merge

update with an empty dict is a no-op, so the first update's auto-derived set survives untouched).
