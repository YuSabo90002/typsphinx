<objective>
Make a table's id anchoring independent of whether its caption happens to render to anything, and
correct the `_emit_id_anchors` docstring that sits next to the same code (TBL-05 and QUA-01, roadmap
SC#2 and SC#3).

Purpose: `visit_table` decides "is this captioned?" structurally and skips its unconditional anchor
call when the answer is yes; `depart_table` decides the same question by truthiness of the RENDERED
caption and only anchors inside the truthy branch. For a table whose title node exists but renders
to the empty string the two disagree, the ids are anchored on NEITHER path, and a surviving `:ref:`
dangles — `typst.compile()` then aborts the ENTIRE document at the label-resolution pass and
produces zero PDFs.

Output: the reproducing GATE-01 fixture, a render-gate test file, a recorded classic-`TypstError`
RED, the `depart_table` anchoring fix, and the QUA-01 docstring correction.
</objective>
