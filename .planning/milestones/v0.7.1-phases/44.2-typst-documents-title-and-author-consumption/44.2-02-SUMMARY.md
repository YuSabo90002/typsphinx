## Accomplishments

- `tests/test_entry_metadata_precedence.py` (17 tests): a discrete-function matrix pinning every `_resolve_entry_element` resolution rule (present-str, empty-string-is-a-value, short-tuple, two-element-tuple, `None`-element, non-`str` warn-then-fallback, no-match, empty-list, malformed-entry-skip, five-element arity, duplicate-docname first-match) plus `map_parameters()`'s D-05 precedence (default mapping: mapped author beats `typst_authors`; custom mapping omitting `"author"`: `typst_authors` survives) and `render()`'s D-04 precedence (explicit `typst_template_function["params"]` wins over the entry-derived value passed into `render()`).
- `tests/fixtures/template_named_dir_master/conf.py`'s second entry gained a divergent author (`"Test Author (nested)"`), making an author-side state leak between the two masters detectable for the first time (only the title side diverged before). `tests/test_template_import_path.py`, the fixture's only consumer, stays green with zero edits (verified before AND after the change).
- `tests/test_multi_master_metadata_no_leak.py` (5 tests): one class-scoped `-b typst` build, positive+negative assertions on both masters' title and author, plus a no-config-fallback control proving the depth-2 master (which diverges from BOTH `conf.py`'s `project` and `author`) never falls back to the config-wide value.
- `tests/test_entry_metadata_route_uniformity.py` (5 tests): one test per template route (A1 bundled default, A2 `<srcdir>/base.typ` shadow with a marker proof that the shadow file was actually used, A3 explicit `typst_template`, A4 package alone) plus the both-configured collapse case, all asserting the entry's title/author reach the output and `conf.py`'s `project`/`author` do not. **Discovered and corrected mid-task:** the plan's own description of A4 ("`typst_template_mapping` LEFT UNSET so the default mapping applies") does not match measured behavior -- `TemplateEngine.__init__` special-cases "package set + mapping unset" to an EMPTY `parameter_mapping`, not `DEFAULT_PARAMETER_MAPPING`, so an unset mapping on the package-alone route produces a bare `#show: project.with()` call with zero arguments. A4's test config instead sets an EXPLICIT mapping equal to `DEFAULT_PARAMETER_MAPPING`'s own contents, matching what every real package-alone user of this extension already does.
- `44.2-GATE-EVIDENCE-02.md`: worktree isolation proof, the full SC#2 matrix table with 17 node ids, the SC#3 fixture-diff-scope proof and before/after consumer runs, the five-row SC#2/D-03 route table, the full-suite reconciliation (873 -> 900, +27 exactly matching this plan's new test count), and the corpus-delta handoff to plan 03 (one new divergent-author entry, `tests/fixtures/template_named_dir_master/conf.py[1]`).

- **Fix:** Moved `build_dir`, `depth1_text`, `depth2_text` to module-level `@pytest.fixture(scope="class")` functions (no `self` parameter), which pytest scopes correctly across the class's test methods without deprecation.
