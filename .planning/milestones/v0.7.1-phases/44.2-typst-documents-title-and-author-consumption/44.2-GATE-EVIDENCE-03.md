## 1. The AST-walk script and the exact commands that run it

Derived fresh this session from the skeleton in `44.2-RESEARCH.md`'s Common Pitfalls Pitfall 1 —
not reused from any prior copy. Enumerates `conf.py` sources via `git ls-tree -r <ref> --name-only`
+ `git show <ref>:<path>` (no `git archive`, no checkout, no working-tree mutation), so the same
script runs unmodified against a historical SHA or against `HEAD`. Compares `entry[2]`/`entry[3]`
against the file's `project`/`author` assignment by AST `Name`-reference OR literal-value equality,
following simple same-file variable aliases. Separately counts inline (non-`conf.py`)
`typst_documents = [` occurrences across every tracked `.py`/`.rst` file. No standalone `.py`
script file was added to the repo — this fenced block *is* the reproducible artifact.

```python
import ast
import subprocess
import sys


def list_tracked_files(ref, suffix):
    out = subprocess.run(
        ["git", "ls-tree", "-r", ref, "--name-only"],
        capture_output=True,
        text=True,
        check=True,
    ).stdout
    return sorted(
        p for p in out.splitlines() if p.endswith(suffix) and ".venv" not in p.split("/")
    )


def show_file(ref, path):
    return subprocess.run(
        ["git", "show", f"{ref}:{path}"],
        capture_output=True,
        text=True,
        check=True,
    ).stdout


def resolve_literal(node, assigns, _seen=None):
    if _seen is None:
        _seen = set()
    if node is None:
        return ("none", None)
    if isinstance(node, ast.Constant):
        return ("literal", node.value)
    if isinstance(node, ast.Name):
        if node.id in _seen:
            return ("name", node.id)
        _seen.add(node.id)
        if node.id in assigns:
            return resolve_literal(assigns[node.id], assigns, _seen)
        return ("name", node.id)
    return ("other", None)


def compare_to_config(entry_elt, config_name, assigns):
    """True/False/None(indeterminate). True = matches config value (by
    Name-reference to config_name OR by literal-value equality)."""
    if entry_elt is None:
        return None
    if isinstance(entry_elt, ast.Name) and entry_elt.id == config_name:
        return True
    entry_kind, entry_val = resolve_literal(entry_elt, assigns)
    config_kind, config_val = resolve_literal(ast.Name(id=config_name), assigns)
    if entry_kind == "literal" and config_kind == "literal":
        return entry_val == config_val
    return None


def analyze_conf_py(path, source):
    result = {
        "path": path,
        "num_entries": 0,
        "four_tuples": 0,
        "five_tuples": 0,
        "other_arities": [],
        "divergent_title": [],
        "divergent_author": [],
        "typst_authors_set": False,
        "typst_template_mapping_maps_author": None,
        "parse_error": None,
    }
    try:
        tree = ast.parse(source, filename=path)
    except SyntaxError as e:
        result["parse_error"] = str(e)
        return result

    assigns = {}
    typst_documents_node = None
    typst_authors_node = None
    typst_template_mapping_node = None

    for node in tree.body:
        if isinstance(node, ast.Assign):
            for target in node.targets:
                if isinstance(target, ast.Name):
                    assigns[target.id] = node.value
                    if target.id == "typst_documents":
                        typst_documents_node = node.value
                    elif target.id == "typst_authors":
                        typst_authors_node = node.value
                    elif target.id == "typst_template_mapping":
                        typst_template_mapping_node = node.value

    if typst_documents_node is None:
        return None

    if typst_authors_node is not None:
        if isinstance(typst_authors_node, ast.Dict):
            result["typst_authors_set"] = len(typst_authors_node.keys) > 0
        elif isinstance(typst_authors_node, ast.Constant) and typst_authors_node.value is None:
            result["typst_authors_set"] = False
        else:
            result["typst_authors_set"] = True

    if typst_template_mapping_node is not None:
        if isinstance(typst_template_mapping_node, ast.Dict):
            keys = [
                k.value for k in typst_template_mapping_node.keys if isinstance(k, ast.Constant)
            ]
            result["typst_template_mapping_maps_author"] = "author" in keys
        else:
            result["typst_template_mapping_maps_author"] = None

    entries = []
    if isinstance(typst_documents_node, (ast.List, ast.Tuple)):
        entries = typst_documents_node.elts
    else:
        result["parse_error"] = "typst_documents is not a list/tuple literal"
        return result

    for idx, entry in enumerate(entries):
        if not isinstance(entry, ast.Tuple):
            continue
        arity = len(entry.elts)
        result["num_entries"] += 1
        if arity == 4:
            result["four_tuples"] += 1
        elif arity == 5:
            result["five_tuples"] += 1
        else:
            result["other_arities"].append(arity)

        entry_title = entry.elts[2] if arity > 2 else None
        entry_author = entry.elts[3] if arity > 3 else None

        title_match = compare_to_config(entry_title, "project", assigns) if arity > 2 else None
        author_match = compare_to_config(entry_author, "author", assigns) if arity > 3 else None

        docname_node = entry.elts[0] if arity > 0 else None
        docname_kind, docname_val = (
            resolve_literal(docname_node, assigns) if docname_node is not None else (None, None)
        )

        if title_match is False:
            result["divergent_title"].append(
                {"index": idx, "docname_kind": docname_kind, "docname_val": docname_val}
            )
        if author_match is False:
            result["divergent_author"].append(
                {"index": idx, "docname_kind": docname_kind, "docname_val": docname_val}
            )

    return result


def count_inline_occurrences(ref):
    py_rst_files = list_tracked_files(ref, ".py") + list_tracked_files(ref, ".rst")
    count = 0
    sites = []
    for p in sorted(set(py_rst_files)):
        if p.endswith("conf.py"):
            continue
        content = show_file(ref, p)
        n = content.count("typst_documents = [")
        if n:
            count += n
            sites.append((p, n))
    return count, sites


def run_walk(ref):
    conf_files = list_tracked_files(ref, "conf.py")
    results = []
    for p in conf_files:
        source = show_file(ref, p)
        r = analyze_conf_py(p, source)
        if r is not None:
            results.append(r)

    total_files = len(results)
    total_entries = sum(r["num_entries"] for r in results)
    total_four = sum(r["four_tuples"] for r in results)
    total_five = sum(r["five_tuples"] for r in results)
    divergent_title_sites = [(r["path"], d) for r in results for d in r["divergent_title"]]
    divergent_author_sites = [(r["path"], d) for r in results for d in r["divergent_author"]]
    typst_authors_files = [r["path"] for r in results if r["typst_authors_set"]]

    inline_count, inline_sites = count_inline_occurrences(ref)

    return {
        "conf_py_files": total_files,
        "total_entries": total_entries,
        "four_tuples": total_four,
        "five_tuples": total_five,
        "divergent_title_count": len(divergent_title_sites),
        "divergent_title_sites": divergent_title_sites,
        "divergent_author_count": len(divergent_author_sites),
        "divergent_author_sites": divergent_author_sites,
        "inline_occurrences": inline_count,
        "inline_sites": inline_sites,
        "typst_authors_with_documents_files": typst_authors_files,
        "results": results,
    }


if __name__ == "__main__":
    ref = sys.argv[1] if len(sys.argv) > 1 else "HEAD"
    walk = run_walk(ref)
    print(f"=== Walk against {ref} ===")
    print(f"conf.py files with typst_documents: {walk['conf_py_files']}")
    print(f"Total parsed entries: {walk['total_entries']}")
    print(f"Four-tuples: {walk['four_tuples']}")
    print(f"Five-tuples: {walk['five_tuples']}")
    print(f"Divergent entry[2] (title != project): {walk['divergent_title_count']}")
    for path, d in walk["divergent_title_sites"]:
        print(f"  {path}[{d['index']}] docname={d['docname_kind']}:{d['docname_val']!r}")
    print(f"Divergent entry[3] (author != author): {walk['divergent_author_count']}")
    for path, d in walk["divergent_author_sites"]:
        print(f"  {path}[{d['index']}] docname={d['docname_kind']}:{d['docname_val']!r}")
    print(
        "Inline (non-conf.py) 'typst_documents = [' occurrences: "
        f"{walk['inline_occurrences']}"
    )
    print(
        "Files combining typst_documents with typst_authors: "
        f"{len(walk['typst_authors_with_documents_files'])}"
    )
    for p in walk["typst_authors_with_documents_files"]:
        print(f"  {p}")
```

### The measured refinement — and a discrepancy against `44.2-CONTEXT.md`'s own D-08 citation

`44.2-CONTEXT.md`'s D-08 states the third condition is conservative because "a file that also sets
a custom parameter mapping omitting `'author'` is also unchanged" (citing plan 01's control-group
evidence for `tests/fixtures/package_only_config_gate/conf.py`). **This session's own real-build
measurement (§5) confirms that case, but also finds a second, unpredicted one:**
`examples/charged-ieee/approach1/conf.py` — which `44.2-CONTEXT.md` D-08 explicitly names as a
site that **"still changes"** (`"Sites that satisfy the first two but still change:
examples/charged-ieee/approach1/conf.py:37 ..."`) — is **measured unchanged**. Its `#show:
ieee.with(...)` call block is byte-identical before and after the D-05 reorder (§5's verbatim
diff). The reason is the SAME special case plan 02 discovered for its own A4 test fixture
(`44.2-02-SUMMARY.md`): `typst_package` is set and `typst_template_mapping` is left completely
UNSET, and `TemplateEngine.__init__` special-cases "package set + mapping is `None`" to an EMPTY
`self.parameter_mapping` rather than `DEFAULT_PARAMETER_MAPPING` — so `"author"` is never an active
mapped key on this route either, and `typst_authors` remains authoritative both before and after
D-05's block reorder, exactly as on the `package_only_config_gate` route, but for a different
reason (no mapping at all, rather than a mapping that deliberately omits `"author"`).

**This is reported as a disagreement, not smoothed over:** `44.2-CONTEXT.md`'s own D-08 citation of
`examples/charged-ieee/approach1/conf.py:37` as a changing site is **not borne out by this
session's measurement**. The measurement wins.

Refined partition:

Live-changing (failing, real observable diff)                                                   = 5
Confirmed inert (neither satisfying nor a live change)                                           = 1

**SC#4's claim rests on the refined partition (105 satisfying / 5 live-changing / 1 inert)** —

### The satisfying set — argued, not built (D-09)

For the 105-entry satisfying set, the argument is D-09's: `map_parameters()` receives identical
`sphinx_metadata["project"]`/`["author"]` values whether they arrive via `entry[2]`/`entry[3]`
(when `entry[2] == project` and `entry[3] == author`) or via the D-02 fallback to
`config.project`/`config.author` (when the entry is absent, short, or `None` — which resolves to

this phase's change alters that comparison.
