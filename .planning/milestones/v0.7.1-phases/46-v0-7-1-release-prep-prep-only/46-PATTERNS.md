```python
        str(page.relative_to(REPO_ROOT))
```

**Defect:** `str(page.relative_to(REPO_ROOT))` yields backslash paths on Windows, which cannot match

owns the exact form):

```python
def _discovered_claim_pages() -> set:
    return {
        page.relative_to(REPO_ROOT).as_posix()
        for page in _iter_rst_pages()
        if _page_makes_contract_claim(page.read_text(encoding="utf-8"))
    }
```
Discretion point left open: whether `EXCLUDED_CLAIM_PAGES` literals also move to the same
normalisation (both sides of the comparison must agree — if `EXCLUDED_CLAIM_PAGES` is already
forward-slash literals, no further change is needed there, but confirm before treating this as done).

**Provenance:** added by Phase 45.1 commit `a6fa38b` ("test(45.1-07): add permanent cross-page
contract-claim guard"); absent from `v0.7.0`. This is a regression the milestone itself introduced.
