## Decisions Made

- **Font choice basis:** "Noto Serif CJK JP" was chosen (over re-trying `HanaMinA`, which automatic fallback had already tried and failed with) because Plan 10's own container measurement (`fc-list`/`typst.Fonts()` run inside the actual RTD build container) enumerated that family, arriving via the `fonts-noto-cjk` apt package already declared in both manifests — no new font binary, no download (T-30.1-24).
- **Executor-added pin-bump trigger:** the plan's own action text does not name triggering the D-08 workflow, but without it the ja build would have checked out the pre-fix parent commit and the entire "does the fix reach the ja artifact" measurement would have been vacuous. Recorded explicitly in `30.1-EVIDENCE.md` as a Rule 3 (blocking-issue) auto-fix using the translations repository's own already-authorized automation, not a scope widening.
- **`lang` auto-derivation regression caught before shipping:** `TemplateEngine.uses_bundled_default_template()` returns `False` for any explicit `typst_template`, so the bundled path's auto-derivation of the Typst `lang` parameter from Sphinx's `language` config would have silently stopped applying. Fixed in `conf.py` by explicitly calling the same public helper and setting `typst_elements["lang"]` — a `conf.py`-only change, not a `typsphinx/` code change.
- **I18N-03/SC#4 verdict kept in the `human_needed` bucket**, not `verified`, even though all three machine checks are now a clean pass — the criterion's own literal ROADMAP.md text includes the owner's visual confirmation as part of the bar itself, and `human_verify_mode: end-of-phase` means this executor defers rather than blocks on it.

**1. [Rule 3 - Blocking] Triggered the D-08 pin-bump workflow to advance the ja submodule pin**
- **Found during:** Task 1
- **Issue:** Pushing the parent's milestone branch alone does not change what commit the ja project's submodule checkout resolves to (translation projects rebuild only from their own repository's commits, per Plan 08's own recorded fact). Without an explicit pin-bump, the ja rebuild this task must observe would still check out the pre-fix parent commit, making the entire "fix reached the artifact" measurement vacuous.
- **Fix:** Triggered `gh workflow run "Update translation source pin" --repo YuSabo90002/typsphinx-doc-translations` (run `30196955986`), polled to completion (success, 21s), confirmed the resulting commit (`656b402`) advanced the submodule gitlink to the new parent commit (`dda4806`) exactly.
- **Files modified:** None in this repository — the translations repository's own already-existing, already-authorized `.github/workflows/update-pin.yml` (D-08) was exercised via its documented `workflow_dispatch` entry point.
- **Verification:** `gh api repos/YuSabo90002/typsphinx-doc-translations/contents/typsphinx?ref=main --jq '.sha'` returned `dda48062a31c06979416ef33a6966a9bcba9a879` exactly, matching the pushed parent commit.
- **Committed in:** Recorded in `f9b4869` (Task 1's evidence commit); no code change of this repository's own tracked files was involved.

**2. [Rule 2 - Missing Critical Functionality] Preserved Typst `lang` auto-derivation under the custom template**
- **Found during:** Task 1, while reading `typsphinx/writer.py`'s `uses_bundled_default_template()` gate per this task's own `read_first` instruction, before any push.
- **Issue:** Setting `typst_template` alone would have silently dropped the bundled default template's auto-derivation of the Typst `lang` parameter from Sphinx's `language` config for **both** builds (every build would fall back to the template's own `lang="en"` default regardless of the actual language) — a real, silent behavioural regression the diff would otherwise have introduced.
- **Fix:** Added `from typsphinx.template_engine import derive_typst_lang` and explicit `typst_elements["lang"] = derive_typst_lang(language)` logic to `conf.py`, reusing the exact same public helper the bundled path calls internally.
- **Files modified:** `docs/source/conf.py`
- **Verification:** Full test suite green (633 passed, 29 deselected); `ruff check` (via `nix-shell -p ruff`), `black --check`, and `mypy typsphinx/` all clean.
- **Committed in:** `dda4806` (Task 1's fix commit)
