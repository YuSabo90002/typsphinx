<objective>
Apply the fix the owner chose, rebuild, and re-run D-03's mechanical checks against a freshly rebuilt
same-source baseline — then state where I18N-03 and the phase's five criteria actually stand.

Purpose: this is the round's closing measurement, and its whole value is that it can come out negative.
A fix that changes a manifest without changing the embedded font list, a rebuild that produces a
byte-identical PDF, a NUL count that drops from ten to three, a page count that still differs by one —
each is a real outcome this plan must be able to record as such. The failure mode being guarded against
is the one milestone invariant #7 names: every mechanical signal reading green while the published
artifact stays wrong. The previous round already caught that once, and only because it compared content
rather than status.

Output: `30.1-EVIDENCE.md` sections carrying the applied change, the observed rebuild, the re-run checks
with both sides' numbers, the English regression evidence where the chosen option requires it, and a
consolidated post-round status for all five success criteria.

waits on the owner except the final visual re-confirmation, which is a `<verify><human-check>` rather
than a blocking checkpoint because `workflow.human_verify_mode` is `end-of-phase`. Autonomous execution
does not mean I18N-03 closes autonomously — it explicitly does not.

option touches it. Under every other option it is not touched, and the acceptance criteria assert it
