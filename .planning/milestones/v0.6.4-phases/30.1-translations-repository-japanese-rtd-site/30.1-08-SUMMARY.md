## Accomplishments

- **WR-01 closed, proven both directions.** Pre-fix: a plain `git clone` (no submodule flag) left
  `typsphinx/` empty; `make locale-update` failed verbatim with
  `sphinx.errors.ApplicationError: ソースディレクトリが存在しません` (Cannot find source directory
  `…/typsphinx/docs/source`), exit non-zero. Post-fix: `git clone --recurse-submodules …` in a second,
  independent fresh clone populated `typsphinx/`, and `make locale-update` completed with **exit status 0**.
- **`update-pin.yml`'s SC#3 root cause repaired, staged and live.** A new step, **`Fetch the tracked
  branch into the submodule`**, inserted immediately after `Set up Python` and immediately before
  `Advance submodule to latest tracked branch` (position 4 of 12 steps, 0-indexed 3), reads
  `submodule.typsphinx.branch` from `.gitmodules` at runtime (no hard-coded branch name), fetches it
  explicitly into `refs/remotes/origin/<branch>`, and verifies the ref exists with
  `git rev-parse --verify` before the `--remote` step runs. The live `typsphinx-doc-translations` copy
  was patched identically and pushed as commit **`1168bb77026300a5e87ba3fd176d4ca34d4ee452`**, proven
  byte-identical to the staged file from a second, independently created clone (not the clone used to
  author the commit).
- **Parent milestone branch advanced.** `origin/gsd/v0.6.4-read-the-docs-migration` moved from
  **`ff8000686aa2d72dd981963f2f0f3a08c9011801`** to **`5297d38c98872cc3587012fe9b1bf5cf6fc48d4a`** by a
  plain fast-forward push (two-dot range notation, no forcing flag, no leading-plus refspec), widening
  the gitlink-to-tip distance from 51 to 77 commits and carrying both this plan's Task 1 and Task 2
  commits.

**Nothing in this plan claims SC#3 is met.** No workflow run was triggered — Plan 09 observes whether

  count (`+1`), not an absolute literal, so this did not block the task — flagged here as a minor
  plan-authoring inaccuracy for the record.
