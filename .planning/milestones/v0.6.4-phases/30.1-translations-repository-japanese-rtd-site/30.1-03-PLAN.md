<objective>
Bring `typsphinx-doc-translations` into existence with its full contents: the owner creates the empty
repository, and this plan populates it — submodule, catalogs, manifest, Makefile, README, workflow — and
then proves the pushed result from a **fresh clone taken back from GitHub**, not from the working copy
that did the pushing.

Purpose: this is the phase's one irreversible-ish structural step, and every failure mode in it is
quiet. A submodule added without an explicit `branch` never advances. A catalog tree copied with its
`.mo` files ships binaries that shadow edited translations. A pin on `main` produces a build Read the
Docs refuses, or worse a build that succeeds in English. Proving the tree from a fresh clone is what
distinguishes "I pushed it" from "it is there".

Output: a populated `typsphinx-doc-translations` on GitHub, and
`.planning/phases/30.1-translations-repository-japanese-rtd-site/30.1-EVIDENCE.md` created with the
first four evidence sections.

and 3 are fully machine-executable and run only after the owner replies.
