<objective>
Remove the GitHub Pages publish path from `.github/workflows/docs.yml` — the
`peaceiris/actions-gh-pages@v4` deploy step and the two now-unused workflow permissions — while
leaving the `typstpdf` regression gate, both artifact uploads, and the tag-time
`Upload PDF to Release` step byte-identical. Install a guard test that makes the removal permanent
and prove that guard is not vacuous. Bring `.planning/codebase/INTEGRATIONS.md` in line with the
reduced workflow.

Everything in this plan is reversible by `git revert`. The irreversible half — deleting
`origin/gh-pages` and disabling the Pages feature — is Plan 03.

Purpose: this is SC#2's repository half and SC#3's byte-unchanged half. Getting the permissions
reduction wrong in the other direction (dropping `contents: write` too) would break the release
attachment silently, at the `v0.6.4` tag, after this milestone has closed.
Output: reduced `docs.yml`, two new guard tests with a recorded red negative control, updated
INTEGRATIONS.md, and appended evidence.
</objective>
