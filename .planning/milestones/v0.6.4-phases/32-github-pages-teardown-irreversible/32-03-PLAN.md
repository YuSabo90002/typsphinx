<objective>
Execute the irreversible half of the teardown, behind everything reversible that came before it:
push the post-teardown tree onto the already-open milestone draft PR and observe a fresh green
`build-docs` run against it, delete `origin/gh-pages` and prove its absence with a live remote
query, then hand the owner-manual Settings → Pages disable across and observe the resulting
`github.io` 404.

observation comes first because it is reversible and proves the reduced workflow actually works;
the branch deletion comes second because it has no undo; the Pages disable comes last because it
depends on a human.

Purpose: this is SC#2's remote half and SC#3's observed-run half. Together with Plan 02 it closes
CI-04.
Output: appended evidence — the pushed head, the cited green run, the ls-remote before/after, the
404 observation, and the milestone-close handoff for the revival hazard.
