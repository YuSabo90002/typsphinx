### Preserved-literal allowlist (do NOT translate these)

Four sites contain CJK characters that are *data*, not prose: samples of rendered output or
config input values being described. Translating them away would destroy the technical claim the
sentence is making. Preserve each and add an inline English gloss:

| File | Literal | Why it must survive |
|------|---------|---------------------|
| ROADMAP.md (one line, in the v0.6.3 detail prose) | the Japanese table label a `language = "ja"` project renders, contrasted with the English form | The sentence's entire point is that the two differ; removing the Japanese form makes it self-contradictory. |
| PROJECT.md (CONF-07 decision bullet) | the Japanese table and figure labels contrasted with their English forms | Same class as above. |
| PROJECT.md (Phase 27.1 validated-requirement bullet) | the Japanese-language string used as a `language` config *value* | It is the input that triggers the Typst fatal the ASCII-only regex exists to prevent. It is a value, not prose. |
| PROJECT.md (Evolution section) | the owner's verbatim original direction, quoted | A quotation's provenance is part of its meaning; render it as a quoted original with an English gloss. |

Rule: after the change, every remaining CJK-matching line must be one of these, and must carry an
English gloss so a reader who cannot read Japanese still understands the sentence. If you find a
defensible way to convey one of these without the literal, dropping it is acceptable — the
acceptance criteria use upper bounds, not exact counts. Finding a *fifth* site you believe must
be preserved is not acceptable without recording the justification in the summary.
