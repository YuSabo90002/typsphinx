<objective>
Remove the multi-language build orchestration from the three files that *drive* it — the task
runner, the CI workflow, and the developer Makefile — leaving the surviving single-language
pipeline internally consistent.

Purpose: `docs/build_multilang.py` is deleted by Plan 02, and three separate callers reference it
by name through strings nothing type-checks: a `tox -e <env>` string in CI, a `python <script>`
line in `tox.ini`, and a `make` target. Under `branching_strategy: milestone` none of those
references is exercised again until the milestone PR opens, so a missed one surfaces as a red CI
run at the moment the milestone is trying to land. This plan closes all three, and repoints the
surviving GitHub Pages deploy step at the tree that will still exist (D-14) rather than deleting
it — the teardown is Phase 32's single irreversible action and must stay behind its own gate.

Output: three modified files, no file deleted, no new file created.
</objective>
